08 · 方程必须面对数据

一条仿真波形，怎样与真实引力波比较？

本章图中的观测曲线来自 LIGO 官方 GW150914 数据发布。你可以检查两个探测器的时差、数值相对论预测与残差。教学模型、探测器噪声和统计证据将在同一条推理链上各就各位。

1. LIGO 测量的不是黑洞的图像

引力波通过时，一组自由落体试验质量之间的距离会发生极微小的相对变化。激光干涉仪比较两条互相垂直的臂，经过仪器响应校准后，将读数转为无量纲应变 \(h\)。数量级上，\(\Delta L/L\sim h\)；对约 4 km 臂长、\(h\sim10^{-21}\) 的事件，差分长度变化是 \(10^{-18}\) m 的量级。精确响应还取决于传播方向、偏振和频率，不能把任意一条臂的变化机械等同于同一个 \(h_+\)。

两个偏振 \(h_+\)、\(h_\times\) 经探测器天线响应 \(F_+\)、\(F_\times\) 投影，才得到探测器里的信号。用 \(I\) 标记探测器：

\[d_I(t)=F^I_+(\mathbf n,\psi)\,h_+(t-\tau_I) +F^I_\times(\mathbf n,\psi)\,h_\times(t-\tau_I)+n_I(t).\]

\(\mathbf n\) 表示天空方向，\(\psi\) 是偏振角，\(\tau_I\) 是传播到该站的时间，\(n_I\) 包括仪器噪声。实际分析还考虑校准误差与频率响应。因此同一事件在 Hanford（H1）和 Livingston（L1）可以有相反的符号、不同的振幅和不同的到达时刻。两条曲线不必每一个峰谷都相等，因为各站噪声并不相同。

GW150914 是由两台 LIGO 探测器共同观测到的双黑洞合并事件。接下来使用的是发现论文 Figure 1 的公开数值数据，时间标签保持论文的约定。这样可以直接检查“论文图里到底画了什么”，并避免混淆不同数据版本、校准版本和自行选择的预处理。

3. 为什么提前 6.9 ms，为什么还要反号？

相隔数千公里的两台仪器接收到同一个波前的时刻不同。GW150914 先到 L1，约 6.9 ms 后到 H1。若令 \(\Delta>0\) 表示将 H1 提前，那么在 L1 的时间坐标上应画 \(d_{\mathrm{H1}}(t+\Delta)\)，再根据两站对该天空方向的响应关系做反号。改变滑块的正方向时要检查这一点，否则很容易把时间差做反。

\[d_{\mathrm{H1,align}}(t)=-d_{\mathrm{H1}}(t+\Delta),\qquad \Delta\simeq0.0069\,\mathrm{s}.\]

这里要区分推断值与画图变换：论文报告的时差约为 \(6.9^{+0.5}_{-0.4}\) ms；实际发布的已对齐 ASCII 曲线使用恰好 7.0 ms 的提前量和反号。把其重叠区间与原 H1 逐样本比较即可验证。因此交互默认 7.0 ms 以精确复现发布曲线，你也可以拨到 6.9 ms 观察这点差别。二者不是相互矛盾的两次测量。

反号不是“为了让证据好看而任意翻转”，而是两站相对方向及该事件偏振投影的可视化近似。对任意天空位置、任意偏振的其它事件，不能沿用同一个负号、时差或振幅。真正的联合分析直接计算各站响应，并共同拟合源参数。

本页的“相关系数”是在当前窗口、共同时间范围内，对两条曲线去均值后计算 Pearson 系数。H1 在 L1 时间点上作线性插值，剩余点不作外推：

\[r=\frac{\sum_k(a_k-\bar a)(b_k-\bar b)} {\sqrt{\sum_k(a_k-\bar a)^2\,\sum_k(b_k-\bar b)^2}}.\]

它在 −1 到 1 之间；它不除以每个频率的噪声，不计算搜索背景，也没有对选择窗口、搜索时延等操作计入试验次数。它既不是匹配滤波信噪比，也不是发现显著性或“相同信号的概率”。短窗口和带通会改变相关结构；峰值附近相关更强、残差偶尔有相关，都不能独立证明或推翻一个事件。

4. 噪声为什么不能只用一条水平误差线表示？

探测器在不同频率上的噪声强度差别很大。低频有地面运动等噪声，高频有光子统计噪声，中间还有窄谱线和瞬态干扰。用一条全频段的标准差描述这些噪声，会把灵敏频段和不灵敏频段混在一起。更合适的描述是功率谱密度（PSD）\(S_n(f)\)：它表示单位频宽贡献多少应变方差，单边 PSD 的单位是 \(1/\mathrm{Hz}\)，其平方根 ASD 的单位是 \(1/\sqrt{\mathrm{Hz}}\)。

\[\langle n^2(t)\rangle=\int_0^\infty S_n(f)\,df,\qquad \mathrm{ASD}(f)=\sqrt{S_n(f)}.\]

实际估计常把较长、远离待分析瞬态的邻近数据分成许多片段，加窗后计算频谱，再用均值或稳健统计组合。这能降低单次谱估计的波动。窗口函数减少片段边界的频谱泄漏，但也改变有效带宽和归一化；因此 PSD 代码必须说明采样率、片段长度、重叠、窗口及单边约定。把 0.21 s 的本页截图片段当作稳定噪声 PSD 的充分样本，是不可靠的。

白化在频域中大致把数据除以 \(\sqrt{S_n(f)}\)，使常见噪声的频率依赖更平坦；精确常数取决于 Fourier 与离散采样约定。白化后纵轴通常不再是原始物理应变单位。带通只是保留一段频带，陷波则压制很窄的谱线；这些操作与白化有不同目的。不要把三者统称“降噪”，更不要滤波后仍把纵轴写成未经改变的原始量。

预处理是分析方法的一部分。对真实数据和比较模板必须应用相容的处理；在长时间片段上滤波，再截取中心窗口，可以避免边缘污染。零相位双向滤波适合离线展示，但它使用未来采样点，不能被误认成实时探测器在那个时刻的因果输出。一个可复现教程要记录这些选择，而不只保存一张看起来干净的图。

5. 匹配滤波：在嘈杂频段少信一点，在安静频段多信一点

假设噪声在分析片段内近似平稳、可用高斯模型描述，就能用 PSD 定义内积。对于两条时间序列 \(a,b\)，令波浪号表示 Fourier 变换：

\[(a|b)=4\,\mathrm{Re}\int_{f_{\min}}^{f_{\max}} \frac{\tilde a(f)\tilde b^*(f)}{S_n(f)}\,df,\qquad \rho=\frac{(d|h)}{\sqrt{(h|h)}}.\]

分母 \(S_n(f)\) 把噪声大的频段降权。若数据中只有某个已知形状的信号加高斯噪声，这类滤波器会有效积累分散在许多周期中的相干信号。实际搜索同时扫描到达时间和相位，并搜索一组覆盖质量、自旋等参数的模板；因此上式的单个 \(\rho\) 只是理解算法的入口，不是完整搜索流水线。

即使某个模板得到较高 \(\rho\)，还要检查信号功率是否按预期分布在频段内、多个探测器是否相容、环境与仪器辅助通道是否存在干扰。短促的仪器 glitch 可能偶然与某些模板部分重合。搜索通常用信号一致性检验修正排名，再通过非物理的站间时间平移或其它背景估计，研究类似噪声事件出现的频率。

因此发现论文中的显著性来自较长数据、搜索与背景估计，不是肉眼看一条红线，也不是把本页短窗口的 Pearson 系数换算成百分比。原始 GW150914 发现分析报告的误报率上界与“5.1σ”应在那次分析和假设下理解，不能用本页的可视化重新宣称已复现同样的统计结果。

6. 从波形拟合到质量、自旋、距离

检测回答“有没有候选信号”；参数推断回答“哪些物理参数能解释它”。设参数向量 \(\theta\) 包含质量、自旋、距离、天空位置、倾角、到达时间和相位。对近似独立的探测器噪声，常用似然为

\[\ln\mathcal L(d|\theta)=-\frac12\sum_I \left(d_I-h_I(\theta)\middle|d_I-h_I(\theta)\right)_I+\mathrm{const},\qquad p(\theta|d)\propto\mathcal L(d|\theta)p(\theta).\]

似然衡量各参数下剩余误差相对噪声是否合理，先验 \(p(\theta)\) 编码允许的范围与假设，后验 \(p(\theta|d)\) 才是报告可信区间的来源。两个参数可以相互补偿：更远但更接近正面观测的系统，可能有与较近但倾斜系统相似的振幅；质量比与某些自旋组合也会在相位上部分退化。一个最优拟合数字无法体现这些关系。

宇宙学红移会拉长观测时间、降低频率。引力波直接测得的时间尺度对应探测器系质量，源静止系质量需要红移校正：

\[M_z=(1+z)M_{\mathrm{source}},\qquad \mathcal M_z=(1+z)\mathcal M_{\mathrm{source}},\qquad f_{\mathrm{obs}}=\frac{f_{\mathrm{source}}}{1+z}.\]

波形振幅约随 \(1/D_L\) 衰减；从光度距离推断红移还需要宇宙学模型，通常并非单凭一个黑洞事件就直接测得独立红移。上一章模型输入写成 \(M_z\)，正是为了防止用源系质量驱动观测时间轴，然后把频率偏差误当作 GR 失效。

作为历史参照，发现论文给出的源系初始质量中位数约为 \(36M_\odot\) 与 \(29M_\odot\)，残骸约为 \(62M_\odot\)，约 \(3M_\odot c^2\) 的能量以引力波辐射。这些都有不确定度，且后续目录会随校准与模型更新数值。它们不是本页数据拟合所得，也不应强制用几个四舍五入的中位数做精确能量闭合。需要当前目录参数时，应查看 GWOSC 事件详情及其明确标注的数据版本。

7. 残差能告诉我们什么，不能告诉我们什么？

令残差 \(r(t)=d(t)-h(t;\hat\theta)\)。若模型捕捉了主要信号，残差中的确定性啁啾应显著减弱。但“残差不为零”是预期之内的：噪声一直存在，参数也有误差，模型和校准亦有误差。反过来，“看起来像噪声”只是一个定性观察。正式检验要考虑噪声分布、频谱和时频结构，并检查是否仍有跨站相干的剩余功率。

本页 NR 曲线是官方示例波形，并未针对这张图精细优化到扣净信号。它与正式的最大后验模板、无模型重建、后验抽样预测带各有不同用途。把该示例残差当成“最佳模型剩余”，再凭一小段看似相似的振荡断言存在新物理，会混淆比较对象。

更严谨的模型检查可以从多个后验参数样本产生预测，叠加符合噪声模型的随机实现，再对数据与模拟使用完全相同的检验统计量。若持续不相容，下一步也应依次调查校准、非平稳噪声、波形近似、预处理与选择效应。真正的理论检验需要明确可证伪的替代理论或参数化偏离，以及能够控制误报的统计流程。

8. 怎样从这张教学图走到独立复现？

第一层是精确复现展示。本地脚本只使用 Python 标准库：下载官方 ZIP，核对固定 SHA-256，解析 11 条 ASCII 曲线，将每条曲线的原始起点 \(t_0\)、间隔 \(dt=1/16384\) s 和数值写入 JSON。部分曲线的 \(t_0\) 与样本数不同，因此不要按数组下标直接相减。应变保存为 \(10^{-21}\) 的倍数，小数保留八位；这远小于图中可见尺度。

python article/blackhole/scripts/prepare_gw150914.py
# 已下载归档也可离线重建：
python article/blackhole/scripts/prepare_gw150914.py --archive Fig1_Data.zip
# 在仓库根目录提供静态 HTTP 服务：
python -m http.server 8000
# 打开 /article/blackhole/observations.html

固定归档摘要为 18784c137497d2b0ad2f95394d4c6f8217ebee7eff6fa45dfc78a42906d560e1。源文件变化时脚本会停止，以免在不知情的情况下换成另一份数据。打开网页后只读取同站点的 JSON；不需要访问 LIGO 服务器。直接使用 file:// 打开页面时，浏览器可能拒绝 JSON 请求，因此建议使用上面的静态服务或已部署的网站。

第二层是从应变自行预处理。从 GWOSC 原始事件发布 下载 H1、L1 的 HDF5 应变及数据质量信息，使用足够长的上下文，核对 GPS 起点、采样率、校准版本和有效区间；估计 PSD，应用窗口与滤波，裁去边缘，再将经过同样处理的波形投影到各探测器。官方教程提供这条路线。本页没有包含长时段原始 HDF5，避免把有限截取误称为完整独立分析。

第三层是重复科学结论。这还需要模板库、搜索背景、校准与数据质量检验、参数估计、后验诊断及系统误差评估。对波形生成，应使用验证过的 LALSuite 等工具，或直接使用有误差估计的 NR 波形。上一章的人工合并拼接可以解释趋势，却不满足这些精度要求。明确复现的层次，才能知道自己理解并验证了哪一步。

练习：哪些操作会改变本页相关系数？

依次改变时间窗口、反号和时延，再切到残差。记录相关系数如何变化。为什么不能从“试遍窗口后最大相关”直接推一个小误报概率？

因为窗口选择改变了样本和频率结构，多次尝试又引入选择偏差；滤波后的相邻样本并非独立。需要对噪声数据执行相同的完整搜索流程，再估计统计量的背景分布。

练习：如果距离加倍，质量也要加倍吗？

不需要。固定其它源参数时，距离加倍主要使振幅约减半；质量变化则会同时改变时间尺度、相位演化与振幅。两者不能靠纵轴任意缩放互相替代。实际宇宙学距离变化与红移有关，要同时区分源系质量和探测器系质量。
