7 Wonders Duel — 本地双人静态网页游戏

打开 index.html 即可玩。无需安装、构建或联网；所有资源均在本目录。
两名玩家共用一台触屏设备轮流操作，支持手机、平板、桌面浏览器。
不同设备之间不联网同步。可用静态文件服务器将本目录提供给局域网设备。

新局可选择：基础版、基础版+万神殿、基础版+议政厅、两个扩展同时开启。
默认同时开启两个扩展。基础版可选官方首局奇迹配置。
点牌后确认建造、弃牌、建奇迹或准备阴谋。特殊效果逐步选择合法目标。
阴谋、神祇选取、秘密进步等内容先显示交接遮罩；对手应主动移开视线。
窄屏点击“城市”展开详情；“对坐模式”翻转玩家2的区域。
每次操作自动保存，包括未完成的特殊效果；刷新后可点“继续结算”。
存储被禁用时会提示。v2 存档与旧版 v1 分开，旧存档保留但不自动转换。

实现范围
基础游戏完整组件；Pantheon 的15神、神门、5大神庙、2奇迹、3进步；
Agora 的13议员、16阴谋、16法令、2奇迹、2进步、政治胜利与新军事标记。
适用本地同屏双人。未实现单人模式及促销卡。
目前两处组件配置仍为待核验值，不能称为100%官方一致，详见 RULES-COVERAGE.txt。
中文名称为项目译名；文字/CSS 界面，不附原版卡牌美术。

文件
index.html 入口；style.css 界面；data.js 组件；engine.js 规则；
app.js 交互/存档；test.cjs 回归测试；reference/SOURCES.txt 规则来源。

验证
运行 node test.cjs。
固定随机种子的800局完整模拟（四种模式各200局），以及全部神祇、全部阴谋、
贸易、连锁、即时胜利、政治胜利、同时科学胜利、隐秘选取、七奇迹锁定等针对性测试。
浏览器检查：双扩展开局、奇迹选取、秘密阴谋选择、议员招募、法令翻面、
回合切换、刷新恢复和390像素窄屏布局。自动模拟不能证明所有规则边界均无误。
