# 照明

静态 HTTP 服务打开 `index.html` 即可游玩。共 **60 个原创固定关卡**，覆盖 5×5、6×6、7×7，每组 20 题；按棋盘尺寸选关，不把搜索统计伪装成人工难度评级。

点击白格放灯；模式按钮切换标叉或擦除。方向键移动焦点，空格/回车操作，X 标叉，Delete 清除。灯的照亮范围即时显示；互照灯和超额邻灯会提示冲突。 支持重开确认、逐关自动保存、撤销、规则弹窗及小屏放大。放大后可左右滑动棋盘。

## 离线关卡生成

```sh
node game/akari/generate.mjs
node game/akari/generate.mjs --check
```

固定 LCG 种子 `0x414b4152`。生成文件 `levels.mjs` 已入库；浏览器直接读取题库，不运行生成器。`--check` 重新执行完整搜索，逐字比较结果且不写文件。请勿单独格式化生成数据；改动生成算法时须重新生成并验证。

生成随机黑格布局，先构造互不照射且覆盖全部白格的灯集，再生成相邻数字。二元求解器传播横纵段至多一灯、每格至少被一灯照亮、编号黑格精确邻灯数的约束，再完整枚举剩余分支。逐步删除部分数字，只保留仍严格唯一的题。最多 200,000 个搜索节点；预算耗尽返回 `complete: false` 并拒收。

对四种旋转及其镜像取规范编码去重。题库数据保存答案及可复查的搜索指标，前端判胜依据规则而非对比预设答案。 `proof.nodes` 是当前算法的搜索节点数，不代表人工难度。

## 验证

```sh
node --test game/akari/model.test.mjs
GAMES_URL=http://127.0.0.1:18769 node game/akari/browser.test.mjs
```

模型测试覆盖全部 60 题、规则边界、旋转镜像去重、预算耗尽处理及固定种子复现。逐题重新穷尽求解，确认恰有一个解。

浏览器测试默认使用已安装的 `playwright` 包和 `/usr/bin/google-chrome`，可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 覆盖。实际检查 1280×900、390×844、320×844：鼠标/触屏、键盘、撤销、刷新恢复、重开取消与确认、规则弹窗、尺寸选关、放大后触摸横移、最大尺寸最后一题完整通关和页面横向溢出。截图输出 `/tmp/akari-<宽度>.png` 及相应 `-won.png`。

存档键为 `akari-v1`，按题目索引保存；撤销记录不跨刷新。后续扩充应追加题目，避免改变已有题目索引含义。没有运行时随机出题或自动提示功能。

规则核对：[Simon Tatham 官方说明](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/lightup.html)。
