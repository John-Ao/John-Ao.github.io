Backgammon 双人触屏游戏

打开方式
直接用现代浏览器打开 index.html，无需依赖或构建。
也可在 backgammon 目录运行：python3 -m http.server 18766 --bind 127.0.0.1
然后打开 http://localhost:18766 。
双方在同一设备轮流操作，不提供联网或 AI 对手。

界面
沿用 ../quoridor 的米白背景、木色棋盘、蓝／赭双色、玩家状态条及紧凑操作区。
宽屏棋盘与操作区左右排列，小屏上下排列。不包含额外导航、品牌或营销内容。

操作
点击“掷骰决定先手”，同点时重掷。随后每回合掷骰，点击己方可动棋子，再点高亮目标。
有被吃棋子时，先点击中栏。收子时点击己方收子区；有两种可用骰子时选择点数。
必须完成当前可走步数后才能结束回合；无合法走法时也可结束回合。
悔棋撤销最后一步移动及其后的回合切换和掷骰，恢复那步移动前的骰子。
新一局需确认。允许本地存储时刷新可恢复；file:// 存储支持取决于浏览器。
采用单局计分（1／2／3 分），不使用加倍骰或比赛局制。

规则参考
https://bkgm.com/rules.html （2026-10-22 查阅）
引擎枚举剩余骰子的完整走法，筛选能使用最多骰子的路径；只能用一骰时筛选较大点数。
支持双骰四次、封锁、吃子、中栏优先入场、精确／超点收子与胜负计分。

文件
index.html：页面与规则说明
style.css：响应式布局
engine.js：独立规则引擎，可通过 CommonJS 在 Node 中测试
app.js：交互、骰子随机数、事件回放存档与悔棋
engine.test.js：规则及自动对局测试

验证
运行 node engine.test.js：13 项测试通过，其中包含 8 局确定性随机对局的棋子守恒与结束检查。
node --check app.js：通过。
