# 匈牙利环

直接打开 `index.html`，或在本目录运行 `python3 -m http.server 8080`。

沿任一圆环拖动珠子，整圈随之转动，松手后对齐位置；交点的珠子由两环共享。目标是让每种颜色的全部珠子在某一圆环上连成一段。支持鼠标和触屏，键盘左右键选择圆环、上下键转动。

打乱通过合法转动生成可还原局面；重置回到初始有序局面。横竖屏按钮旋转棋盘布局，不依赖浏览器锁定设备方向。棋盘默认根据窗口方向选择布局，并随可用空间缩放。

样式和规则参考：[Jaap's Puzzle Page — Hungarian Rings](https://www.jaapsch.net/puzzles/rings.htm)，[实物图片](https://www.jaapsch.net/puzzles/images/hungring.jpg)。每环 20 个位置、两个共享交点、38 颗珠子；黄/蓝各 9 颗，红/绿各 10 颗。页面参考 `beads` 的柔和四色、细线轨道和灰度菜单按钮，采用无高光、无阴影的平面绘制。


所有操作集中在右上角菜单。打乱和重置需要确认；支持全屏（浏览器允许时）、日夜主题和横竖布局。

开启计时后，首次转动开始计时，复原后自动停止。暂停计时也会暂停棋盘操作；继续后可接着操作。打乱、重置或重新开启计时会清零。

局面、主题、方向及计时状态保存在当前浏览器的 localStorage 中，刷新后自动恢复。运行中的计时包含刷新或离开页面的时间；暂停状态不会累加。浏览器禁用存储时无法持久保存。

“分享当前局面”生成携带 38 颗珠子颜色的 URL，接收者打开即可导入相同局面，计时从零开始。导入后移除 URL 中的局面参数，后续刷新恢复本地进度。分享给其他设备时，页面需要通过对方可访问的 HTTP(S) 地址打开；本地文件或 localhost 地址不能跨设备访问。

棋盘屏蔽触摸滚动、滚轮、右键菜单、文本选择及原生拖放，菜单和分享输入框仍保留正常交互。
