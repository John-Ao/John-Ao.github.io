# Blokus

直接用现代浏览器打开 `index.html`，无需安装依赖或联网。也可在此目录运行 `python3 -m http.server 8080`，通过 `http://localhost:8080` 访问。手机、平板可通过同一局域网内电脑的 IP 和端口访问（需系统允许入站连接）。

支持双人和四人同屏对战。双人：玩家一使用蓝、红，玩家二使用黄、绿。四人：玩家一至四分别使用蓝、黄、红、绿。点击棋块区右上的人数按钮，在新对局弹窗中选择人数；确认后开始新局，取消保留原局。模式与进度一同保存，旧版双人存档可继续使用。棋块上的黑点标明定位格。选择棋块后，棋盘以圆点显示当前朝向的所有合法落点；点按圆点预览，旋转或翻转，用方向按钮微调，然后确认落子。支持拖动预览、棋盘随窗口自适应、合法位置提示、自动跳过无棋可下的颜色、终局计分及本机自动保存。不是联网对战。

规则来源：Mattel 官方说明书，2026-10-19 查阅：
https://service.mattel.com/instruction_sheets/R1983%20-%20Blokus.pdf

使用其经典版 20×20 棋盘及双人／四人规则，每色 21 块棋，按每人控制的颜色计分；所有颜色均不能落子时结束。计分按本游戏自定义的正计分方式：棋盘上每格得 1 分，每人所控颜色的格子数合计为玩家总分，没有额外奖励分；总分高者获胜。网页将起始角固定标色，帮助触屏定位。

`engine.js` 为独立规则引擎；`app.js` 为交互和存档；`style.css` 为响应式布局。运行规则验证：`node test.cjs`。

布局按窗口宽高自动选择左右或上下排列，在保留全部棋块与操作按钮的前提下尽量放大棋盘。对局主界面无需滚动，详细规则在弹窗内阅读。已检查 320×480、390×667、640×360、800×600、1280×720 窗口尺寸。

点击上方任意玩家得分卡，可查看该玩家各颜色尚未使用的棋块，以及剩余块数和格子数。双人显示该玩家的两色，四人显示一色；查看不会改变回合或当前落子预览。
