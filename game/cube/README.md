# 魔方

访问 `/game/cube/`，或直接打开 `index.html`。纯静态实现，不依赖第三方库或网络资源；需要 WebGL 和 Pointer Events。

- 菜单最上方使用九档图标切换长方体、金字塔、斜转、五魔方、SQ-1、八面体、二十面体、齿轮和魔表，首行固定显示“类型”，长方体等图标为单面的填充贴纸图案（长方体为九宫格），八面体和二十面体显示完整立体外形并按可见面整体填充；悬停提示及无障碍标签保留类型名称。类型、阶数及尺寸仅在关闭菜单时统一应用；调整时不改变当前局面。若设置有变化且当前未还原，弹窗询问“是否保存当前状态”，选择“是”会保存到历史并收藏，再应用新设置。
- 魔表类型使用单面 3×3 表盘图标；长（横向表盘数）、宽（纵向表盘数）独立设置为 2–6，默认 3×3。正反面支持自动、左右或上下排列，四角圆弧支持拖动或按钮转动，也可用方向键操作。销钉控制相邻 2×2 表盘联动，四角表盘与反面镜像反向联动；3×3 规则与原 `magic_clock` 一致。销钉和转动都支持撤销、重做、存档及分享；计时、主题、全屏沿用 cube 控制。
- 长方体显示 X/Y/Z 三条尺寸；金字塔显示 2–5 阶的单条切换条；五魔方显示 2–7 阶的单条切换条；斜转显示 2–7 阶的单条切换条，八面体和二十面体各显示 3/5 阶的单条切换条；SQ-1 不显示阶数。不再显示应用按钮，关闭菜单时应用选择。
- 新类型支持直接拖动转层、打乱、复原、撤销、重做、本地恢复和分享。金字塔、斜转、八面体每步 120°，五魔方和二十面体每步 72°，SQ-1 上下层 30°、中层翻转 180°；切面被完整块跨越时不可转动。SQ-1 从右半中层起滑可翻转，从上下层起滑可转动对应层。旧长方体存档和分享链接继续兼容。
- 菜单内通过各占一行的 1–9 分段切换控件独立设置 X（宽）、Y（高）、Z（深），选中档位以滑动底色标示，与低亮度控件风格一致，均为 1–9 的整数，默认 3 × 3 × 3。应用尺寸会复原并清零计时。
- 从任意魔方块（包括贴纸间的黑缝）开始拖动，根据点击块与同面相邻块中心连线的屏幕投影，比较完整移动轨迹与各行列方向的夹角，持续匹配包含该块的一层，不在起手时锁定方向；轨迹按移动距离加权，后续主要方向可以纠正起手偏移，接近两层分界时保持预览稳定。拖动实时预览，松手补齐一个转动步长；拖回起点或取消指针操作不转层。
- 转轴垂直的截面为正方形时步长为 90°，否则仅允许 180°。例如 2 × 3 × 3 的 X 层可以转 90°，Y、Z 层只能转 180°。所有尺寸均包含内部层；1 × 1 × 1 仍支持转动。
- 只有从空白处开始拖动才调整整体视角。第二根手指加入时取消转层预览，双指捏合缩放、扭转绕视线轴旋转，松手保留视角；剩余单指不会误触转层。鼠标滚轮缩放。不提供转层按钮或键盘旋转操作。
- 长方体、斜转和 SQ-1 的底部四个正方体框线图依次表示：关闭对齐、正对、2/3 正面 + 1/3 顶面、正面 + 上面 + 右面。默认三面视角。整体拖动结束后向最近的对应朝向平滑对齐，开始新手势可打断对齐。双面模式对正方体的正面和顶面投影高度比为 2:1；长方体保留同样的观察角度。
- 日夜模式下方的圆圈问号打开操作帮助，以半透明遮罩在各按钮原位置直接显示文字，角度对齐区域用框和“角度对齐选项”标注，中央保留手势说明，不显示关闭按钮或箭头；查看时暂停累计计时，点击任意位置或按 Esc 返回。
- 四角分别为菜单、日夜模式、打乱、复原；角度切换上方为转层撤销和重做。打乱和复原需要确认；尺寸变更在关闭菜单时应用。菜单另有低亮度和全屏开关。
- 顶部计时器保留手动开始、暂停/继续和清零。每次打乱清零计时并建立一轮历史，首次有效转动开始计时，首次完整复原停止并固定该轮记录；后续转动、再次复原和刷新不会自动清零或再次计时。从初始局面转动不自动计时。用户手动开始的计时也在首次复原时停止，后续操作不自动重启。魔表销钉不触发计时；菜单、帮助打开和页面进入后台时暂停累计。
- 历史记录展示保存局面的缩略图、类型、尺寸/阶数、阶段、用时及日期，支持收藏与恢复局面，收藏优先显示；未收藏最多保留 100 条，收藏不自动清理。缩略图按保存的操作游标重建局面，魔方保留保存视角，魔表显示正反面；仅在进入可见区域时绘制，不改变当前局面。未完成轮次随进度更新，已完成轮次保留首次复原的局面与用时。
- 菜单内可生成并复制分享链接，包含尺寸、局面、撤销/重做记录、视角和用时；打开链接后可继续操作，计时初始暂停。
- 局面、尺寸、操作记录、视角、对齐模式、显示偏好和用时自动保存在本地，刷新恢复。尚未提交的拖动预览不写入存档。

`model.js` 使用半整数格点表示块中心，整数单位向量表示贴纸朝向，每次合法转动精确回到格点；`game.js` 使用透视投影和 WebGL 深度测试绘制块体和贴纸，对完整长方体外壳进行射线拾取，拾取射线从透视相机出发，在屏幕空间比较点击块与同面相邻块连线的投影方向（边界沿行列方向延伸），而非块绕轴转动时离开该面的瞬时速度来匹配滑动方向。

## 验证

```sh
node game/cube/model.test.cjs
node game/cube/clock.test.cjs
```

覆盖全部 729 种尺寸、每一个层的合法角度和逆转、连续转动复位、60 步打乱后逆序复位、块占位唯一性、贴纸保持在外表面，以及中心/棱/角上的手势方向匹配。

浏览器测试需要 Playwright 和 Chrome。在仓库根目录启动静态服务器后运行：

```sh
python3 -m http.server 18765 --bind 127.0.0.1
# 在另一终端运行
node game/cube/browser.test.cjs
node game/cube/clock.browser.test.cjs
node game/cube/session.browser.test.cjs
node game/cube/thumbnails.browser.test.cjs
```

可用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径、`CHROME_BIN` 指定浏览器路径、`CUBE_URL` 指定页面地址。测试覆盖 WebGL、转层与整体拖动分离、撤销/重做、刷新恢复、四种对齐模式、尺寸表单、180° 手势、手机布局、黑缝拾取和取消手势。

`polyhedra.js` 负责六种非长方体的凸多面体切割、合法转层和还原判断；`types.js` 负责类型菜单、多边形渲染、射线拾取和转层手势。

新增验证：

```sh
node game/cube/polyhedra.test.cjs
node game/cube/types.browser.test.cjs
```

覆盖全部可选阶数、整周转动、60 步合法打乱及逆序还原、SQ-1 阻挡切面拒绝，以及各类型菜单、阶数应用、实际拖动、撤销/重做、刷新、分享、打乱/复原和 320px 手机布局。浏览器测试沿用上述服务器与环境变量配置。

斜转按正方体棱边的实际线段数命名，支持 2–7 阶，默认 2 阶。各阶切面严格避开正方体顶点。二阶保持原有结构；三阶及以上每条棱两端角块的宽度为内部线段的 1/2，内部线段等宽，总段数等于阶数。八面体仍绕三角形面中心转动，切面将每面划为等大的三角形，3/5 阶分别每面 9/25 块。二十面体改为 12 条顶点转轴，每次转动 72°，3/5 阶同样每面 9/25 个等大三角形。各档位生成不同分块，使用实际几何判断合法转层。

金字塔的底部图标采用四面体框线，依次为关闭、单面、双面、三面对齐；分别朝向面的法线、两面共用的棱、三面共用的顶点，拖动结束后吸附到最近的对应朝向。八面体、五魔方（十二面体）和二十面体仅显示关闭、正对两个图标，正对以各自模型的实际面法线为准。帮助说明同步更新；旧存档中这些类型的双面或三面对齐模式自动归为正对，关闭状态保持不变。

运行 `node game/cube/alignment.browser.test.cjs` 验证类型对应的选项和图标、金字塔可见面数、面法线对齐、拖动吸附、关闭对齐、刷新恢复及旧模式兼容。

偶数阶五魔方采用角块风格的分块：2 阶只有 20 个角块，每面 5 片贴纸；4/6 阶将各面的五个角区继续细分，并把跨面角块、棱块合为一个活动块。各层按块的定位点选择，转动与撤销均同时旋转定位点及块体；转动完成后的外表面保持完整十二面体。奇数阶沿用原来的模型和操作记录。

所有魔方的游戏贴纸先在自身平面内沿各边等距内缩，再进行透视投影。内缩距离按整体显示比例换算，正面缝隙约 3.2 CSS 像素，侧面随透视自然变窄，避免固定屏幕像素侵蚀侧面贴纸。极小贴纸不足以内缩时不绘制彩色部分；拾取仍使用完整块体。内缩后的顶点保留在原始面上，投影后深度正确。

运行 `node game/cube/stickers.test.cjs` 验证正反顶点序下的等距偏移、过小贴纸消失、透视深度，以及偶数阶的块数、每面贴纸数和转动后的外表面覆盖。类型浏览器测试同时覆盖 2/4/6 阶的拖动、撤销、分享和刷新恢复。

切割间距验证：`node game/cube/cuts.test.cjs` 检查上述各阶所有棱的等分点、三角形面积及二十面体顶点轴/72° 步长。旧二十面体转面存档的操作不能直接用于新转角模型；加载时原存档备份至 `cuboid.session.v1.icosahedron-face-backup`，当前二十面体复原并提示。旧转面分享链接会拒绝载入并保留本地局面；新分享链接记录模型版本。

旧斜转档位 3/5/7 自动更名为 2/4/6。旧基础档的操作可继续恢复；旧高阶的过顶点切割操作无法套用，新模型复原前将原存档备份至 `cuboid.session.v1.skewb-vertex-cut-backup`，旧高阶分享局面拒绝导入并保留本地局面。

齿轮魔方固定规格，无阶数或尺寸控件。外层每步转 180°，中层联动 90°，其中四个齿轮额外自转 60°；拖动预览、撤销、重做、打乱、存档和分享均使用同一联动模型。棱块参考 `gear_cube.png`，采用圆润六齿轮廓；彩色表面沿正方体棱折成相邻两个平面，各侧使用所在面的颜色，外缘保留连续黑边，内部三角网格不产生贴纸缝。运行 `node game/cube/gear.test.cjs` 验证联动、12 步周期及混合转动的逆序恢复。

斜转角块只绕自身当前所在的角旋转；二阶中心块及没有合法内层候选的非角块，将手势位移向量映射到所在面的八个方向分区，选择与手势同半平面内最接近垂直的角转轴，再由该轴的旋转切向确定正反转。正对时，若向上为缝隙 1，顺时针八等分，轴在 1/3/5/7，则 2～3 区逆时针绕轴 1，7～8 区顺时针绕轴 1。边界上优先保持当前轴；选轴和转向均不依赖起点位置，拖动过程中实时更新。三阶及以上的内部对角线块保留两个交叉角转轴及一个独立中间层，以块的面中心为固定参考，按三种转动的正反切向形成六个手势分区，分界为相邻切向的角平分线，不强制六等分；具体起点不影响选轴及转向。其他有内层候选的非角块优先选择两道相邻切面之间、包含点击块的独立内层，再按滑动方向与各候选转轴的屏幕运动方向的对齐程度选择转轴，不按点击位置选择最近角；内层转动时两侧外层保持不动。没有内层候选时，同一转轴下选包含点击块的最小转层。角块的拖动决定正反方向与转动进度；中心块与高阶内层的拖动同时决定转轴。此规则适用于 2–7 阶及已转动的局面。运行 `node game/cube/skewb-layers.test.cjs` 验证各内层的手势可达性、两侧静止和逆转；运行 `node game/cube/skewb-gesture.test.cjs` 验证角块归属、二阶中心面块的四个区域、正反手势及转动后的识别。

齿轮角块的三个外表面采用带圆润凸齿和凹口的曲线轮廓，中心贴纸为四瓣形；凹多边形先完整内缩再进行耳切三角化，避免内部网格缝。独立的静止球形内核遮挡内部空隙，不参与拾取；不再使用随中心块转动的整面底板，避免中间帧穿模。角块拖动只选择与所触面相交的侧层，角块随外层刚性旋转 180°，中层仍联动 90°。类型图标由相同轮廓生成，显示四角、四棱及中心共九片单面贴纸。

SQ-1 的上下层切割线关于面的两条中轴对称，角块占 60°、棱块占 30°，三层高度均为总高度的 1/3。中层翻转轴与切割线一致，类型图标同步显示对应贴纸。运行 `node game/cube/sq1.test.cjs` 检查镜像对称、层高和切面阻挡。

八面体拖动沿用金字塔的切层方向判定：排除与所触面法线平行的转轴，按切割线在屏幕上的方向匹配手势。运行 `node game/cube/octahedron-gesture.test.cjs` 验证 3/5 阶所有贴纸在复原及转动后局面中的选轴，覆盖双向拖动和倾斜视角。

八面体新增独立中央层与五阶内层；手势仅选择互不重叠的单层，旧整组转动编号保留用于存档回放。运行 `node game/cube/octahedron-layers.test.cjs` 检查完整分层与未选中层保持静止，`node game/cube/octahedron-layers.browser.test.cjs` 验证 3/5 阶中央层的实际拖动、存档、分享和撤销。

八面体和二十面体均支持 3、4、5、6 阶，每面分别为 9、16、25、36 个等大三角形。八面体偶数阶包含中心切面，两侧内层可独立转动，不生成零厚度的中央层；奇数阶保持独立中央层。二十面体各阶均绕顶点转动 72°。

五魔方拖动按所触面的切割线选轴，排除绕该面中心的旋转，并只转动所选单层。偶数阶按块定位点选择，奇数阶按几何切面选择。相关验证：`megaminx-gesture.test.cjs`、`megaminx-layers.test.cjs`、`megaminx-layers.browser.test.cjs`。

二十面体 3–6 阶仅保留外层及相邻切面之间的独立内层，手势只在所触面的三个顶点轴方向中按切线选择单层；不保留旧层编号兼容。齿轮棱块只允许触发包含该棱块的外层转动，不再由棱块直接选择中层转轴；中层机械联动保持不变。验证见 `icosahedron-gesture.test.cjs`、`icosahedron-layers.test.cjs`、`icosahedron-layers.browser.test.cjs` 和 `gear-edge.browser.test.cjs`。

五魔方已移除跨越多个层的整组中央区域转动，模型和打乱仅允许外层及相邻切面之间的单层。2/3 阶只有外层，高阶保留逐层内层；不保留旧层编号兼容。

单层规则复查：二十面体已移除宽度为普通单层约 7–12 倍的中央整组区域。八面体、斜转和金字塔保留由相邻切面限定的单层。SQ-1 中间层按自身结构翻转，齿轮魔方中层仍按机械规则联动。

斜转六分区验证：`node game/cube/skewb-diagonal.test.cjs` 覆盖 3–7 阶、六个方向、分区边界、起点平移和透视；`node game/cube/skewb-diagonal.browser.test.cjs` 验证两个角转轴和中间层的双向拖动、撤销重做及保存恢复。

奇数阶五魔方按实际阶数等分每条棱，七阶每段为棱长的 1/7，五阶为 1/5；相邻平行切面的间距统一为 (3−√5)/阶数，避免旧公式使中央一段固定占 1/3。验证：`node game/cube/megaminx-spacing.test.cjs`。

所有六面魔方统一使用上白、下黄、左绿、右蓝、前红、后橙，SQ-1 顶面为白色。长方体菜单 X/Y/Z 分别表示上下高度、左右宽度、前后深度；尺寸应用与回显使用相同映射。验证：`node game/cube/six-face-colors.test.cjs`。
