Frosthaven — 双人合作静态网页

打开 index.html 即可离线游玩。无需安装依赖或构建。
可选：在此目录运行 python -m http.server 8080，用浏览器访问 localhost:8080。
两位玩家使用同一触屏设备轮流操作；支持对坐翻转、棋盘缩放与横向滚动。
角色牌和怪物数据已本地内置，查看原始牌面图片和场景书 PDF 需要联网。

与旧版本的区别
已移除 PvP 流程与原创八张牌，改为共同对抗怪物。
旧 PvP 存档不会混入合作版本。合作进度自动保存，也可导入/导出 JSON。

开始
1. 创建两个不同职业。默认六个起始职业，“显示已解锁职业”可用其余职业。
2. 在战役中配置手牌与物品，选择场景和难度。
3. 场景 0 已按官方场景书第 3 页及章节 2.1 内置地图、开门揭示、
   限定手牌、宝箱 47 和轮末胜利判定，可以直接开始。
   其他场景须按场景书用布置工具设置；其预铺地图仅供练习。
4. 分别选双卡或长休息。按先攻执行上/下半行动。怪物执行官方行动牌。
5. 未自动支持的效果会明确暂停。用裁定工具按牌面落实，再点击确认继续。
6. 按场景书核对目标并确认胜利；回城结算后人工补充特殊奖励与剧情条件。

自动实现
- 角色等级生命、手牌上限、官方能力牌名称/先攻/数据；双卡、基础上下行动。
- 角色与怪物先攻、怪物类型共用行动牌、精英先于普通、编号排序。
- 普通攻击、标准 20 张修正牌、优势/劣势、穿透、护盾、近战反击。
- 普通移动、盟友穿越、困难地形、陷阱与危险地形、门状态。
- 治疗、中毒、流血、眩晕、定身、缴械、混乱、强化、隐形、守护、脆弱等。
- 烧一张手牌或两张弃牌抵伤；已选双卡不能用于抵伤。
- 长休息、短休息及一次受伤重抽、手牌耗尽、双人全部耗尽才失败。
- 普通召唤物放置、下一轮起行动、跟随召唤者使用修正牌。
- 基础怪物聚焦寻路、负面地形优先避让、普通行动序列。
- 元素轮末衰减、拾取、进度存档、撤销与日志。

辅助实现 / 已知限制（不是全部官方玩法自动化）
- 职业复杂文本、形态限制、持续触发、阵型和区域攻击、元素消耗加成、
  强制移动、特殊召唤能力、物品效果、非标准修正牌专长，需要人工裁定。
- 多目标怪物最佳站位、特殊目标优先级、滑冰地形、墙线边界争议需要裁定。
  视线使用六角形多点采样，只由墙/门阻挡；不是数学上完备的精确几何。
- 除已核对的场景 0，其他场景资料没有格子坐标，地图必须照场景书布置。
  特殊场景目标、章节生成、谜题和复杂剧情条件未自动执行。
- 战役内置场景、物品、事件、任务和建筑资料。时间、资源、升级与物品记录
  可管理；专长改牌、个人任务、退休、城镇攻击、建筑成本/效果、事件条件、
  互斥分支和特殊奖励需要人工处理。不是完整 138 场景战役的自动复刻。
- 物品购买自动检查金币；解锁条件、锻造材料、装备槽位由玩家核对。
- 自动普通结算保留经验/战利品/基本解锁；特殊奖励仍须按场景书确认。
- 战利品牌采用基础数量模型（双人木材/金属/毛皮每份为 2）；钱币卡面变体、
  随机物品及特殊战利品牌仍请在战役资源记录中核对修正。
- 原始牌面为英文，可展开查看。中文规则数据不全时显示英文。
