# 星系

静态 HTTP 服务打开 `index.html` 即可游玩。共 **60 个原创固定关卡**，覆盖 4×4、5×5、6×6，每组 20 题；按棋盘尺寸选关，不把搜索统计伪装成人工难度评级。

点击格线画边界，再次点击删除；Tab 配合空格/回车操作，Delete 清除。满足连通、唯一圆心、180°对称的区域会淡绿显示；多余的区域内部边界不能通关。 支持重开确认、逐关自动保存、撤销、规则弹窗及小屏放大。放大后可左右滑动棋盘。

## 离线关卡生成

```sh
node game/galaxies/generate.mjs
node game/galaxies/generate.mjs --check
```

固定 LCG 种子 `0x47414c41`。生成文件 `levels.mjs` 已入库；浏览器直接读取题库，不运行生成器。`--check` 重新执行完整搜索，逐字比较结果且不写文件。请勿单独格式化生成数据；改动生成算法时须重新生成并验证。

用包含 S 形、十字、H 形及矩形的中心对称多连方填满棋盘；每题至少包含一个非矩形区域。圆心支持格心、边心与四格交点。求解器从圆心周围必属该区域的格子开始，成对加入旋转对应格，枚举所有连通、中心对称且不占用其他圆心核心格的区域，再进行全盘精确覆盖。候选区域和覆盖搜索共用 150,000 次工作预算；耗尽返回 `complete: false` 并拒收，不将不完整搜索当作唯一解。

对四种旋转及其镜像取规范编码去重。题库数据保存答案及可复查的搜索指标，前端判胜依据规则而非对比预设答案。 `proof.nodes` 是当前算法的搜索节点数，不代表人工难度。

## 验证

```sh
node --test game/galaxies/model.test.mjs
GAMES_URL=http://127.0.0.1:18769 node game/galaxies/browser.test.mjs
```

模型测试覆盖全部 60 题、规则边界、旋转镜像去重、预算耗尽处理及固定种子复现。逐题重新穷尽求解，确认恰有一个解。

浏览器测试默认使用已安装的 `playwright` 包和 `/usr/bin/google-chrome`，可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 覆盖。实际检查 1280×900、390×844、320×844：鼠标/触屏、键盘、撤销、刷新恢复、重开取消与确认、规则弹窗、尺寸选关、放大后触摸横移、最大尺寸最后一题完整通关和页面横向溢出。截图输出 `/tmp/galaxies-<宽度>.png` 及相应 `-won.png`。

存档键为 `galaxies-v1`，按题目索引保存；撤销记录不跨刷新。后续扩充应追加题目，避免改变已有题目索引含义。没有运行时随机出题或自动提示功能。

规则核对：[Simon Tatham 官方说明](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/galaxies.html)。
