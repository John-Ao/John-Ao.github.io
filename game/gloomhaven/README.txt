Gloomhaven — 双人合作静态网页游戏
================================

运行
----
直接用浏览器打开 index.html 即可，无构建工具、无联网依赖。
也可在本目录执行：python -m http.server 8000
然后使用电脑或同一局域网的触屏设备访问 http://电脑IP:8000。
两位玩家在同一设备轮流操作，合作对抗自动控制的怪物；不支持两台设备联网。

本次替换了此前的 PvP 对战实现。合作存档使用独立的 gloomhaven-coop-v2 键，
不会读取或覆盖原对战存档。支持自动存档，以及 JSON 导出 / 导入。

实现内容
--------
采用 2017 原版，不与 Gloomhaven 第二版混用。
- 两个职业：蛮族、织法者。合计 28 张经原卡数值核对的能力牌：
  全部 1 级 / X 级牌，以及每个职业两张 2 级候选牌；升级时二选一。
- 双卡选择、先攻、上下半区、基础行动、经验、弃牌 / 损失 / 持续牌。
- 轮末短休息（随机损失、承受伤害重抽）、先攻 99 长休息、耗尽。
- 单次伤害可损失一张手牌或两张弃牌抵消；锁定的待出牌不算手牌。
- 六角地图、房门揭示、墙体视线、移动与跳跃、困难地形、沿途陷阱、
  多目标 / 范围攻击、推挤、护盾、穿透、反击、掉落与拾取。
- 三种怪物：强盗守卫、强盗弓手、活骷髅；各自 8 张官方能力牌，
  0–3 级普通 / 精英属性；怪物聚焦、自动寻路、避陷阱、远程避免劣势。
- 中毒、创伤、定身、缴械、眩晕、困惑、强化、隐形；六元素生成、
  消耗与衰减；优势 / 劣势；引擎支持祝福 / 诅咒牌。
- 神秘盟友召唤与自动行动；多次持续效果；复苏以太回收损失牌。
- 六种基础物品、装备栏、商店、金币 / 经验结算、2 级升级、
  可选数值专长（蛮族四种、织法者三种）、两个可选战斗目标。
- 3 个自建合作练习场景：清剿、宝箱撤离、坚守与增援。
- 逐项伤害结算、战斗记录、卡牌堆查看、地图缩放、触控与键盘操作。

尚未实现 / 已知近似
------------------
不是完整官方数字版，也不声称实现了全部官方玩法。
- 未收录官方 95 场景、原版地图及剧情；现有地图、宝箱奖励、
  练习场景解锁链为自建内容，不是官方场景 1 / 2 / 3。
- 未实现其余职业、3–9 级能力牌、完整专长树（滚动 / 附加效果修正）、
  完整物品、随机战斗目标牌堆、城市 / 道路事件、声望、繁荣、
  成就、捐赠、个人任务、退休、卡牌强化、隐藏内容与扩展。
- 经验可以继续累计，但当前升级上限是 2 级，不生成虚构高级牌。
- 视线采用顶点间采样；极端擦边几何可能与桌面人工裁定不同。
- 怪物等效路线 / 目标选择使用稳定顺序；穿刺喷发的等长路径自动选择。
- 飞行、传送、拉拽、怪物召唤和首领特殊能力尚未实现。
- 部分行动的附加效果自动执行，没有实现所有可选效果的独立开关。
- 攻击牌中名称使用便于阅读的中文译名；英文名称可用于对照原卡。

来源（查阅 2026-10-20）
----------------------
官方规则入口：https://cephalofair.com/pages/gloomhaven
原版规则书：https://online.flippingbook.com/view/598058/
原版规则 PDF 镜像：https://cdn.1j1ju.com/medias/8d/c5/21-gloomhaven-rulebook.pdf
重点核对：规则书 17–32 页的战斗机制，33 页场景结算及 42–47 页成长。
原卡数值参考：https://github.com/any2cards/worldhaven
怪物数值交叉核对：https://github.com/johreh/gloomycompanion
仅转写机制数值；网页不分发官方插画、扫描卡图或剧情文本。
本项目为非官方实现，Gloomhaven 相关名称属于原权利人。

文件
----
index.html          页面入口
style.css           响应式 / 触控布局
engine.js           与界面独立的规则引擎，可由 Node 加载
 data.js            职业能力、怪物能力、物品及练习地图
monster-stats.js    怪物各等级属性
 game.js            界面、交互、自动保存、存档导入导出
 test.cjs           规则回归测试

验证
----
node --check engine.js
node --check game.js
node test.cjs

已运行 37 项规则检查；浏览器检查覆盖选牌、揭示、怪物自动行动、
伤害决定、完整回合、刷新恢复、规则对话框、手机布局。
另运行 12 场自动流程模拟，覆盖失败和坚守胜利。
