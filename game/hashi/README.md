# 桥梁

静态 HTTP 服务打开 `index.html` 即可游玩。共 **60 个原创固定关卡**，覆盖 5×5、7×7、9×9，每组 20 题；按棋盘尺寸选关，不把搜索统计伪装成人工难度评级。

点击岛间虚线依次设置单桥、双桥、清空。Tab 切换桥位，空格或回车切换；数字 1/2 设置桥数、0/Delete 清除。桥数过多或桥梁交叉有即时反馈。 支持重开确认、逐关自动保存、撤销、规则弹窗及小屏放大。放大后可左右滑动棋盘。

## 离线关卡生成

```sh
node game/hashi/generate.mjs
node game/hashi/generate.mjs --check
```

固定 LCG 种子 `0x48415348`。生成文件 `levels.mjs` 已入库；浏览器直接读取题库，不运行生成器。`--check` 重新执行完整搜索，逐字比较结果且不写文件。请勿单独格式化生成数据；改动生成算法时须重新生成并验证。

在随机岛屿可见图上构造不交叉生成树，随机加入双桥及额外可用连边，计算岛上度数。对每条候选桥枚举 0/1/2，传播岛度数和交叉约束，同时检查潜在连通性。找到第二解即拒收；只有搜索穷尽且恰有一解才收录。搜索最多 100,000 个节点，预算耗尽明确返回 `complete: false`，该题被拒收。

对四种旋转及其镜像取规范编码去重。题库数据保存答案及可复查的搜索指标，前端判胜依据规则而非对比预设答案。 `proof.nodes` 是当前算法的搜索节点数，不代表人工难度。

## 验证

```sh
node --test game/hashi/model.test.mjs
GAMES_URL=http://127.0.0.1:18769 node game/hashi/browser.test.mjs
```

模型测试覆盖全部 60 题、规则边界、旋转镜像去重、预算耗尽处理及固定种子复现。逐题重新穷尽求解，确认恰有一个解。

浏览器测试默认使用已安装的 `playwright` 包和 `/usr/bin/google-chrome`，可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 覆盖。实际检查 1280×900、390×844、320×844：鼠标/触屏、键盘、撤销、刷新恢复、重开取消与确认、规则弹窗、尺寸选关、放大后触摸横移、最大尺寸最后一题完整通关和页面横向溢出。截图输出 `/tmp/hashi-<宽度>.png` 及相应 `-won.png`。

存档键为 `hashi-v1`，按题目索引保存；撤销记录不跨刷新。后续扩充应追加题目，避免改变已有题目索引含义。没有运行时随机出题或自动提示功能。

规则核对：[Simon Tatham 官方说明](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/bridges.html)。
