# Hive（昆虫棋）

纯静态 HTML/CSS/JavaScript，同一台设备上双人轮流对战，无依赖、无需构建。直接用现代浏览器打开 `index.html` 即可离线使用。

手机访问：在本目录执行 `python -m http.server 8000`，手机与电脑连接同一局域网，在手机浏览器打开 `http://电脑局域网IP:8000`。

点选待放棋子或己方场上棋子，然后点绿色合法落点。拖动棋盘平移，双指缩放；可用按钮缩放与居中。「对坐模式」翻转黑方棋子区。支持悔棋、双方议和、重新开始和浏览器本地自动存档。规则弹窗包含详细说明和来源。

实现基础版，每方蜂后 1、兵蚁 3、蚱蜢 3、甲虫 2、蜘蛛 2。包含第四回合蜂后限制、蜂后入场前禁移、蜂群连通、滑动间隙、甲虫堆叠高度及顶层归属、胜负及双蜂后同时被围平局判定。无合法行动时提供跳过按钮；循环僵局由双方议和，不强制采用三次重复规则。不含扩展棋子和联网对战。

规则来源（2026-10-19 查阅）：

- [Hive 官方规则入口](https://hivegame.com/download/rules.pdf)
- [Gen42 基础版规则 PDF，图书馆镜像](https://www.whistlerlibrary.ca/cover-images/hiverules.pdf)
- [基础版规则文字版](https://www.ultraboardgames.com/hive/game-rules.php)

运行规则测试：`node engine.test.js`。11 项测试包含规则边界及 15 局确定性随机对局的棋群连通与棋子数量检查。浏览器已验证选择、落子、轮换、悔棋、刷新恢复，以及 390×844 视口无页面溢出。真机双指手势尚未实测。

文件：`engine.js` 为独立规则引擎，`app.js` 为界面与手势，`style.css` 为响应式布局，`engine.test.js` 为 Node.js 测试。
