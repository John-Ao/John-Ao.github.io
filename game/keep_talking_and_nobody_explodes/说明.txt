Keep Talking and Nobody Explodes — 非官方静态网页改编

运行
直接打开 index.html，无需构建或安装依赖，可离线使用。
也可在本目录运行 python3 -m http.server 8080，访问 http://localhost:8080。
手机访问同一局域网电脑的 http://电脑IP:8080（网络与防火墙需允许）。

双人合作
玩家一操作炸弹并描述颜色、符号、文字、灯和箱体信息；玩家二查询手册给出指令。
支持同屏并排、同屏面对面（专家区域旋转180度）、仅炸弹、仅手册。
双设备打开同一网页，专家选择“仅手册”或访问 index.html#manual；无需房间和状态同步。
不提供联网语音，双方现场或通过自己的语音工具交流。
同屏不能强制防止偷看，可隐藏手册。手机屏幕较小时建议使用双设备。
独立滚动、触屏按钮、指针捕获支持一边按住按钮/放电杆、一边查手册。
Space / Enter 可按住按钮和放电杆。触摸取消或窗口失焦会取消按压；倒计时不暂停。

已实现：官方 v1 / Verification Code 241 全部模块类型
1. 电线：3–6根电线，按数量、颜色及序列号判断。
2. 按钮：颜色/文字/电池/指示灯优先规则；短按、长按、条带与定时松开。
3. 符号键盘：官方六列符号，四键按列序输入，保留正确输入进度。
4. 四色闪光：含/不含元音及0/1/2次失误的映射表；3–5阶段，循环闪光。
5. 文字判断：28种显示文字、28张优先表、三阶段，保留英文原文以保留谜题。
6. 记忆：五阶段，位置/数字回溯，失误回到第一阶段。
7. 摩斯电码：16个单词与频率，点划灯光循环、字符间隔及单词间隔。
8. 复杂电线：红/蓝/星/灯的16种组合，完整维恩逻辑，串行号/电池/并行接口。
9. 电线序列：四页九根线，红蓝黑分别跨页计数；可返回；漏剪会阻止翻页并记失误。
10. 迷宫：官方九张6×6地图，双圆标记、隐藏墙、碰墙失误。
11. 密码：35词词库、五列各六个候选字母，保证唯一可用密码。
12. 排气：定时回答 VENT GAS? / DETONATE?，回答/超时判定和循环激活。
13. 电容放电：按住放电、松开积累、过载失误与循环激活。
14. 旋钮：八组官方12灯阵、旋转UP基准、到时方向判定与循环激活。

任务
入门：3模块 / 5分钟 / 3次失误。
标准：随机5种常规模块 / 5分钟 / 3次失误。
全部常规模块：11种各一个 / 15分钟。
持续维护：随机8种常规 + 3种维护 / 12分钟。
高压：随机6种常规 / 3分钟 / 1次失误。
自定义：选择1–11种模块（每种一个、至少一个常规），1–60分钟，失误上限1或3。
选单个常规模块即可练习。

通用规则
所有常规模块解除即胜利，不需要永久解除维护模块。
达到失误上限或时间耗尽即失败。一次失误后主计时1.25倍，两次后1.5倍。
主计时少于一分钟显示秒.百分秒，按钮判定使用当前显示的数字。
后台仍按经过的时间计时。刷新网页会丢弃当前局。
箱体信息包括序列号、AA/D电池节数、亮/灭指示灯和各类接口。

明确的改编差异
本版是2D操作面板，不包含官方战役/解锁进度、3D箱体翻转、原作音效、VR、模组和联网房间。
任务组合为本版自定，不称为官方任务。每局最多11个模块，暂不支持同类型重复模块。
按钮长按阈值400毫秒；摩斯单位时长220毫秒；四色闪光可手动重播并清空当前输入。
维护时序是本版参数：首次操作后第12/17/22秒依次激活，之后待机20–35秒。
排气激活窗口40秒，VENT GAS概率75%；旋钮45秒；电容激活后距过载30秒、放电速率每秒9单位。
维护小计时采用真实秒，不随主计时加速。切后台取消按住状态。
复杂电线手册把官方维恩图改为等价16组合表。
手册中文解释为本项目整理；文字判断与密码保留英文；键盘符号图来自官方手册。
