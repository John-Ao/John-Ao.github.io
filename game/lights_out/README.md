# Lights Out

直接打开 `index.html` 即可使用，无需安装依赖。也可运行 `python3 -m http.server 8080` 后访问本地页面。

按下后可连续拖动，经过的格子会依次触发，离开后再次进入同一格子会再次触发，格子内移动不会重复触发；快速划过也会补齐途经格子。点击格子会使自身及上下左右相邻格子一起变色，边缘不会跨行或环绕。全部变暗即完成。默认 5×5、三色循环（暗 → 中 → 亮 → 暗）；菜单中的设置支持分别调整行数和列数（各 3 至 10），及双色循环（暗 → 亮 → 暗）。更改设置后生成可解的新局面。

界面沿用 beads2 的平面风格和右上角灰度菜单；格子以不同亮度的灰度表示状态，普通夜间模式仅将界面切换为深色，格子保持正常亮度；菜单中的“低亮度”开关独立降低格子亮度，默认关闭，并自动保存。鼠标和触屏操作不显示焦点描边，键盘操作保留焦点提示。支持打乱、重置、日夜主题、全屏、可暂停计时、步数、自动保存和分享局面。打乱通过合法操作生成，重置回到全暗局面，两者均需确认。首次打开为全暗棋盘，可从菜单打乱开始。

开启计时后首次点击开始，完成时停止；暂停同时禁止棋盘操作。刷新恢复局面、设置和计时，运行中的计时包含离开页面的时间。浏览器禁用存储时无法保存。

分享链接包含棋盘大小、颜色模式及局面，导入后计时与步数清零。跨设备分享需部署到对方可访问的 HTTP(S) 地址，本地文件和 localhost 链接不能跨设备使用。

支持鼠标、触屏；Tab 聚焦格子，方向键移动焦点，空格或 Enter 点击。

旧版方形棋盘存档与分享链接仍可导入，新分享链接保存独立行列数。

棋盘自动最大化至可用区域，保持格子为正方形并避开菜单按钮和计时器；底部不显示说明文字。
