# 魔表

直接打开 `index.html`，或在本目录运行 `python3 -m http.server 8080`。

参考 beads2 的简洁平面棋盘与右上角菜单。棋盘无文字说明，裁去内部留白，按可用空间最大化显示，并避让悬浮菜单与计时器。正反面同时显示，默认随屏幕横竖方向自动排列，也可在菜单中手动选择布局。

- 目标：使两面所有指针指向 12 点。
- 点击四个销钉切换状态，实心表示向当前面凸起，空心表示按下；背面的位置左右镜像、状态相反。
- 四角表盘外侧显示半透明四分之一圆弧，沿圆弧拖动，每 30° 转一格。菜单的“拨轮交互”可切换为按钮模式：圆弧拆为两个带方向箭头的八分之一圆弧，按下即转一格，以当前面为准。
- 支持鼠标、触屏和键盘。Tab 选择控件，空格切换销钉，方向键转动拨轮。
- 提供合法打乱、确认重置、日夜主题、全屏、计时与暂停。首次转动开始计时，还原自动停止；暂停时禁止棋盘操作。
- 局面、设置与计时保存在 localStorage；运行中的计时包含离开页面时间。禁用存储的浏览器无法保存。
- 分享链接包含两面表盘及销钉状态，导入后计时清零。跨设备分享需要双方均可访问的 HTTP(S) 地址。

规则参考：[Jaap's Puzzle Page — Rubik's Clock](https://www.jaapsch.net/puzzles/clock.htm)。同状态销钉对应的拨轮联动；凸起侧带动相邻表盘，另一侧仅对应角表盘反向联动。

验证：`node model.test.cjs`。覆盖全部 16 种销钉配置、两面四个拨轮的转动及逆转、镜像联动、12 格周期和随机合法操作逆序还原。
