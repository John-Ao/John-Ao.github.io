# 五魔方

直接打开 `index.html`，或访问静态站点的 `/game/megaminx/`。不需要构建、网络资源或第三方库；浏览器需支持 WebGL、Pointer Events。

## 操作

- 单指 / 鼠标拖动调整视角，魔方跟随拖动方向转动。手势模式下，常规外形选中面后，从该面上一条边对应的棱块或两个角块内沿边滑动，拖动时实时预览共享该边的相邻层转动，松手后补齐到 72°，保留原面选择；其他位置或方向的拖动仍调整视角。双指操作或取消手势不会触发转层。
- 菜单可切换手势 / 按钮模式，默认手势模式，选择会在本地保存。按钮模式下拖动只调整视角，使用悬浮箭头转面。手势模式保留中心点，只隐藏悬浮箭头按钮；从中心块起滑可直接转动该面，无需先选中，拖动时实时预览旋转，松手后补齐到 72°；反向拖动可回退，拖回起点或取消手势不转动。滑动绕面中心的方向决定顺逆时针；经过正中心的滑动按主方向判定：向右 / 下为顺时针，向左 / 上为逆时针。
- 菜单中的“自动切换中心点”开启后，随视角自动选中最正对屏幕的面。“角度对齐”开启后，在视角拖动结束或方向键松开时，以约 280 毫秒的缓入缓出动画将最正对的面摆到正对屏幕，并将最靠上的一条边对齐为水平；新的拖动或方向键操作可立即打断动画，关闭开关也会停止动画。两个开关独立控制，默认开启，本地记忆设置；转层预览和动画期间暂缓自动调整。
- 点击中心块选择面；边块、角块和空白处不会选择转轴。选中后，手势模式以金色高亮面的外边缘（常规外形转动时保持面边框稳定）；按钮模式框出整个旋转层在当前视角下的最外侧轮廓，覆盖所有参与转动的块。不描画贴纸缝隙。
- 按钮模式下，中心点左上、右上的半透明弧形箭头分别逆时针、顺时针转动 72°。中心点和按钮均为二维叠加，共用转轴上的固定参考点；转面和切换形态不会移动按钮，调整视角时随之移动，转轴朝向背面时隐藏。转动动画期间按钮保持可用，按钮和 A / D 键的连续输入按顺序排队执行，不丢失操作。出现排队时，当前动画连续加速，后续排队转动缩短至每步 90 毫秒；单次操作仍为 230 毫秒。
- 双指拖动观察，捏合缩放；鼠标滚轮缩放。
- 底部左箭头撤销、右箭头重做，位于打乱 / 复原按钮内侧。手动转层每次算一步；开启角度对齐时，一次整体视角拖动（或方向键操作）及随后的对齐合为一步，按发生顺序撤销 / 重做。新操作清除重做分支，动画期间暂不可用。撤销记录保留在当前页面会话中，刷新、载入局面、打乱或复原会清空；打乱步骤不计入撤销记录。
- 常规 / 异形开关只更换外壳，保留局面、选中的转轴、视角和缩放。转动动画和打乱过程中暂时禁用开关。
- 四角依次为左上菜单、右上日夜模式、左下打乱、右下复原。顶部显示计时器，形态切换位于菜单中。
- 菜单支持“新建魔方”（选择常规或异形，初始为还原状态）和“切换魔方”；新建与切换前自动保存当前局面，列表标明当前魔方、状态、用时和创建时间。复用历史记录存储，未收藏最多保留最近 100 条，收藏不参与自动清理，刷新后继续上次选中的魔方。
- 菜单包含常规 / 异形、手势 / 按钮模式、自动切换中心点、角度对齐、低亮度、全屏、分享局面、历史记录；切换项统一使用双态滑块，点击菜单外部空白处可关闭菜单；历史记录支持 JSON 导入导出。不提供重置视角操作。
- 打乱和复原均先弹出确认框；取消、按 Esc 或点击框外空白处不执行操作。打乱执行 60 个转动，每步动画 40 毫秒（实际耗时受设备帧率影响）；手动转动每步 230 毫秒。复原保持形态和视角，清除选择、取消动画，并新建一局。
- 游戏界面中，方向键调整视角，选中面后 A / D 转层；键盘事件在捕获阶段拦截，不改变焦点或触发滚动。菜单、输入框、输入法组合输入及 Ctrl / Command / Alt 快捷键保留正常行为。

## 计时、保存和分享

点击顶部计时器可打开计时控制：未开始时显示“开始”；已开始时暂停并显示“清零”。清零需再次确认，确认后归零并等待重新开始，不改变魔方局面。点击弹窗外空白处、关闭按钮或按 Esc，恢复原本运行中的计时；清零后保持未开始。首次手动转层自动开始计时；打乱不计时。打开菜单或切换到后台暂停计时，返回后继续。几何局面还原后停止计时。每轮打乱到复原持续更新同一条历史；未完成时再次打乱、复原按钮、还原后手动转动均不额外新增记录。完成后再次打乱才开始下一条历史。手动新建魔方立即记录，其首次打乱沿用该记录。默认初始魔方和分享链接仅自动保存当前进度，打乱后进入历史。

使用当前浏览器的 localStorage 自动保存最近 100 局未收藏记录及所有收藏记录。刷新恢复块状态、形态、视角、缩放、选中面、累计用时以及尚未完成的转动队列及各步速度；不计关闭页面的时间。计时期间定期保存，离开页面时同步保存。低亮度 / 日夜偏好也会保留。存储不可用时显示提示，可以导出记录备份。

分享链接将当前局面、形态、视角和用时编码在 URL 片段中，无需后端，不会自动向外部发送。打开链接会创建一条新的本地记录；分享前的局面仍在历史中。历史导入会校验版本、转动数据、视角和用时，同编号记录保留较新者，当前局面不被覆盖。

## 图片推测与模型边界

照片显示十二面体外形、十二种颜色、白面的大五边形中心及侧面的斜切、长条块。照片没有转动过程和内部机构，因此不能唯一确定转轴、切割深度、隐藏面的邻接关系。

本实现是可转动的几何近似，不是对实物机构的识别结论。模型以正十二面体为外壳，用十二个平面切割为 62 个活动块和一个内部核心；每个初始外表面有 11 片贴纸。切割轴相对外壳绕共同的白色轴偏转 24°，深度取内切球半径的 0.79 倍。这两个数是视觉近似参数，不是从照片测得的精确值。白面中心朝向、部分三角块和长条块边界仍与照片有差异，背面的颜色邻接也采用推测。

所有转动实际旋转块体顶点和贴纸，使用 72° 步长，会发生形变。转动前检查是否存在横跨切面的块；不存在则整层转动。没有模拟轴承、卡扣和转动过程的实体碰撞。

`model.js` 独立负责半空间切割与转动；`game.js` 负责 WebGL 深度渲染、拾取、动画与指针交互。外部贴纸在屏幕空间沿各边等距内缩 1.6 CSS 像素，相邻贴纸间的黑缝为 3.2 CSS 像素，不随块大小或视角改变。`session.js` 负责会话格式校验、分享编码及暂停计时，`game.js` 接入浏览器保存与恢复。

## 常规与异形的状态映射

两种几何使用相同的十二个切割轴。异形切割深度保持 0.79；常规切割深度为 √5 / 3（约 0.74536），将每条外棱分为等宽的角块、棱块、角块。常规外壳的面法向与转轴一致；异形外壳沿用照片近似的偏转。用块所在的切割半空间组合编码稳定 ID，而不是依赖几何数组顺序。每个块保存三个局部基向量，记录完整的空间朝向，包括中心块的自转。

切换时生成另一种外壳的初始几何，按 ID 应用当前块的朝向；不重置、不重放操作历史。贴纸随各自外壳切割生成，因此异形块的贴纸数量和轮廓可以与常规块不同，映射的是同一物理块及其空间姿态。复原保持当前外形。

## 验证

运行 `node game/megaminx/model.test.cjs`，检查 12 面分块、每个转轴的正反抵消、连续五次转动复位，以及 200 步打乱后逆序复位。

额外验证两种外形的块 ID 一一对应、120 步交替切换转动与参考局面一致、跨外形逆序还原，以及常规外壳转动后保持十二面体。

运行 `node game/megaminx/session.test.cjs` 验证分享 / 历史数据往返、无效数据拒绝和嵌套暂停计时。模型测试还覆盖常规 / 异形局面的快速恢复及还原判断。

存档列表左侧显示实际局面缩略图，右侧星标可收藏或取消收藏；收藏置顶，刷新和 JSON 导入导出保留收藏状态，不受普通历史记录数量限制。

“已还原”用时提示仅在点击打乱后首次通过转动（含撤销 / 重做）还原时出现；再次手动转乱并恢复不重复提示。复原按钮结束本轮但不弹成功提示。提示资格随存档保存，刷新或切换不重置。
