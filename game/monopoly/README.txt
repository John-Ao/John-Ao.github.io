Monopoly / 大富翁 — 双人同屏经典规则版

启动
直接用现代浏览器打开 index.html；无需安装或编译，无外部资源依赖。
也可在本目录执行 python3 -m http.server 8000，再访问 http://localhost:8000。
两位玩家共用手机、平板或电脑轮流操作，可开启对坐模式。

规则版本与来源（2026-10-20 核对）
以 Hasbro C1009（2016/2017）经典美版棋盘及规则为基准：
https://instructions.hasbro.com/en-nz/instruction/monopoly-classic-game
https://instructions.hasbro.com/api/download/C1009_en-nz_monopoly-classic-game.pdf
传统详细规则补充（整组出售建筑等）：
https://www.hasbro.com/common/instruct/monins.pdf
https://www.hasbro.com/common/instruct/Monopoly_Vintage.pdf
牌组采用该时期的经典事件，中文表达；每副16张，不使用2021年后的公益基金新事件。
版本说明：C1009采用固定所得税200、奢侈税100，公用事业落地后重新掷骰计租；
未混入早期10%所得税选项、快速规则、自由停车奖金、玩家借贷或免租协议。

操作与规则
1. 每人1500，随机掷骰比较决定先手。经过或停在起点收入200。
   双数追加回合，连续第三次双数直接入狱；正常路过监狱仅是探视。
2. 无主地产可以原价购买；拒绝购买必须拍卖，落地者也可竞买。
   拍卖10起价、至少加价1，两人随时点击自己的出价按钮。
   “不再加价”是当前价格的落槌确认，不是永久退出；新出价使所有确认失效。
   所有竞买人确认才成交。银行清算时仅未破产者可以报价。
   拍卖中可卖房、抵押、交易筹款；最高报价的现金被预留，避免重复花费。
3. 地主手动点击“索租”。依C1009文字，下一位玩家掷骰前仍可索取；
   结束回合本身不会免租，同一玩家双数连掷时可积累待索取的租金。
   下一位玩家开始掷骰时，尚未索取的租金失效。
   租金按落地时的产权与建筑确定；抵押地产不收租。
4. 点击棋盘地契、或玩家资产列表管理地产，双方在对手回合及监狱中均可操作。
   建造须完整色组且全组无抵押，均匀建造、均匀出售。
   4栋房屋可升级酒店；全局仅32栋房屋、12座酒店。
   每次建造先进入双方需求计划，可以追加多栋、撤销、选择位置。
   双方确认后，库存足够则按标价购买；需求超过库存且双方争购时逐个竞拍。
   竞得后立即放在该玩家计划的下一块合法地产，直到库存或需求耗尽。
   房屋和酒店分别申报，避免未完成的建造操作互相占用库存。
   建筑分配中先完成当前事务，再进行下一项资产操作。
5. 卖房按半价且均匀出售；酒店拆为4栋房屋时银行必须有4栋库存。
   可以整组清售建筑。抵押前须卖掉该色组全部建筑。
   赎回支付抵押本金加10%利息，零头向上取整。
6. 交易可以交换地产、现金、出狱卡，不能直接转让建筑。
   每处抵押地产的接收方选择立即赎回（本金+10%）或付10%保留抵押。
   后者未来赎回时仍须再次支付本金+10%。最终方案双方确认后才生效；
   更改抵押接收方式会清除之前的确认。
7. 入狱不领取起点工资，本回合立即结束，但仍可收租、交易和管理地产。
   之后可付50、用出狱卡或尝试双数；第三次失败必须付50并按原骰子移动。
   以双数出狱不会额外掷骰；先付钱或用卡出狱后的双数遵循正常规则。
8. 机会及公益基金各16张，抽到后执行并放回牌底；出狱卡留在持有人手上，
   直到使用或因欠银行破产而归还原牌堆。持有两张时可指定使用或交易哪张。移动卡会处理新位置、起点与嵌套抽卡。
   最近铁路卡租金翻倍，最近公用事业卡按新骰子十倍计租，维修按实体建筑计费。
9. 现金不足时进入债务处理，可卖房、抵押或交易筹款，之后点击支付。
   若卖掉所有建筑并抵押全部未抵押地产仍可付清，不允许直接宣告破产。
   欠玩家破产：建筑按半价折现，剩余现金、地产、出狱卡转交债权人；
   债权人逐处处理继承的抵押地产，必要时也进入筹款阶段。
   欠银行破产：现金回银行、出狱卡回牌底、地产解除抵押并逐一拍卖。
   清算结束后判定最后未破产玩家获胜，不跳过资产处理。

存档
自动保存在当前浏览器 localStorage，刷新可继续。
旧版存档原位升级，保留资产、现金与未完成阶段；旧版已结算事项不追溯重算。
同一对局的建造计划、拍卖报价、待索租金、债务与遗产接收都可恢复。
不同浏览器、文件地址或端口不共享存档；禁用存储时会提示。
重新开始需确认，随后覆盖当前存档。

文件与验证
index.html / style.css / app.js：触屏界面、双方确认与存档。
engine.js：独立规则引擎。
test.cjs：执行 node test.cjs 运行回归测试。
41项测试覆盖规则边界、存档升级与20局至多各2000步演练；检查现金、牌堆、
均匀建设和建筑库存守恒。浏览器验证建造申报、稀缺建筑竞拍、重新报价、
手动索租、抵押地产接收和破产后判胜。

本地同屏信任制；没有服务器、身份认证或在线多人同步。
