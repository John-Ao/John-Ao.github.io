# 数织

静态 HTTP 服务打开 `index.html` 即可游玩。共 **128 题**：原来的 8 个图案关卡保留顺序与内容；新增 5×5、7×7、10×10 各 40 题。选择器按尺寸、每 20 题分组，切组时保留各题进度。

支持涂色与标叉拖动、一次拖动一次撤销、键盘、重开确认、逐关自动保存和小屏放大。放大后在数字区域左右滑动，格子仍用于涂画。

## 离线关卡搜索

```sh
node game/nonogram/generate.mjs
node game/nonogram/generate.mjs --check
```

`generate.mjs` 用固定种子 `0x4e4f4e4f` 和固定 LCG 参数搜索候选，结果写入 `levels.generated.mjs`。浏览器直接读取结果，不在运行时生成或求解。`--check` 在内存中完整重跑并逐字比较文件，不写入文件。

每题须满足：

- 涂色比例为 32%–70%，没有全空或全满的行列。
- 至少一半行列含两个或更多分开的色块，排除简单实心形状。
- 行列约束枚举只有一个完整解。求解器先对两轴候选传播约束，再枚举候选最少的行或列；找到第二解即拒绝，只有穷尽其他分支后才接受唯一解。
- 将四种旋转及各自镜像取最小编码，排除与原 8 题或已收录题目的同构重复。

本版本分别检查 121、77、80 个候选，得到各尺寸的 40 题。数据中的 `proof.branches` 和 `proof.passes` 仅为该求解算法的分支数和传播轮数，用来复核生成结果，不代表人工难度。新增题为抽象逻辑图案，未虚构图像主题或人工难度等级。

`curated.mjs` 单独存放原 8 题；新增题只追加在后面。存档继续使用 `nonogram-v1` 和原索引 0–7，旧进度无需迁移。修改生成算法或种子会影响新增题的索引含义，后续扩展应继续追加，不能直接替换已有题。

## 验证

```sh
node --test game/nonogram/model.test.mjs
GAMES_URL=http://127.0.0.1:18769 node game/nonogram/browser.test.mjs
```

模型测试逐题检查 128 题唯一解、旋转镜像去重、尺寸数量、筛选约束、搜索指标、生成可复现与原 8 题内容哈希。另用独立的全盘枚举校验全部 512 个 3×3 图案对应的解数，避免仅依赖生成器自身验证。

浏览器测试支持 `PLAYWRIGHT_MODULE`（模块路径）和 `CHROME_PATH` 覆盖，默认使用已安装的 `playwright` 包与 `/usr/bin/google-chrome`。测试桌面 1280×850 和手机 390×844、320×844，覆盖触屏、键盘、拖动撤销、空白起点擦除撤销、放大后触摸横移、存档、重开、规则、通关和横向溢出。新增覆盖原 8 题旧存档逐题恢复、分组选择、最后一题 10×10 的刷新恢复与实际完整通关。截图输出 `/tmp/nonogram-*.png` 与 `/tmp/nonogram-generated-*.png`。

撤销记录不跨刷新保留。没有运行时随机出题和提示求解功能。
