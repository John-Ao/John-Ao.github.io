# Qawale

静态页面，无运行时外部资源。同屏双人及基础人机，遵循 [Gigamic 官方规则](https://export.gigamic.com/wp-content/uploads/2022/08/GIGAMIC_GCQW_QAWALE_RULES-MLV_08-2022_BD.pdf)：4×4 棋盘四角各两枚中立石，双方各八枚；选择非空堆，加己石后从底到顶正交播撒，不能立即折返，可以绕圈重访。只计顶层横竖斜四连，双方储备都耗尽且无人连线则平局。

本页在完整播撒后判胜；若同时四连，行动者优先。这是明确展示的实现裁定，官方规则未具体说明同时四连优先级，不将其宣称为官方条款。

点击棋堆后显示待播撒顺序，点击合法邻格形成路线，最后确认。预览不会写入存档或消耗储备，取消、撤销及刷新都安全退回完整回合。格子可访问标签包括全部堆叠颜色顺序。支持方向键、Enter / 空格、重绘焦点恢复、撤销、新局确认及自动保存。

AI 对各候选堆采样有界完整合法路线（通常最多 1024 条），选八条较优候选并检查对手最多 128 条回复；长堆不会无界枚举。休闲 AI，不保证找出所有战术。

```sh
node --test game/qawale/model.test.mjs
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs GAMES_URL=http://127.0.0.1:18769 node game/qawale/browser.test.mjs
```

浏览器测试覆盖 1280×800、390×844、320×844、844×390，含键盘完整路线、预览与存档隔离、确认/取消/撤销、AI、规则、真实胜局及恢复。模型另测底部先播、立即折返、绕圈、顶层判断、完整 AI 对局及长堆预算。
