# 连四棋（Quarto）

纯静态双人游戏，支持本地同屏与 Portal 在线对战，入口 `/game/quarto/`，使用独立样式。

16 枚圆角矩形棋子各有左右两个图案。左侧为圆形／倒三角，颜色为蓝／橙；右侧为五角星／菱形（方片），颜色为紫／绿。四位编码依次表示左侧形状、左侧颜色、右侧形状、右侧颜色，组成全部 16 种组合。横、竖或长对角线四子共享任一属性即自动判胜。日夜模式使用相同色系，深色模式提高图案亮度。

玩家一先选棋交给玩家二；收到棋子的一方落子后继续选棋交给对方。待放置棋子在候选区保留并显示选中环；已放置棋子留下空位。横屏左右各八枚，竖屏上下各八枚。

页面显示棋盘、候选棋子、悔棋、重开、日夜间切换和联网按钮。联网时显示自己的席位、回合及连接状态。默认跟随系统主题，手动选择后本地保存。支持本地自动存档与获胜连线高亮，结束时使用游戏内弹窗显示结果。回合说明通过无障碍状态与按钮提示提供。新版存档使用 `quarto-clover-v1`，不覆盖旧版含手动宣告设置的存档。

没有人机。棋子由本项目 SVG 绘制，未使用官方美术。引擎保留进阶和手动判胜能力，当前页面使用标准自动判胜模式。

规则：https://export.gigamic.com/wp-content/uploads/2021/01/INS-RULE_QUARTO-CLASSIC_11-2016.pdf

## 在线对战

点击“联网 → 创建房间”，通过 Portal 管理员或普通游戏密钥登录，再生成邀请链接发给对方。访客打开链接后点击“加入邀请对局”，无需房主密钥。房主是玩家一，先选棋交给玩家二；落子后同一玩家继续为对方选棋。双方都在线且消息已确认时才允许操作。

悔棋撤回最近一次选子或落子，重开清空当前局并由玩家一先选棋；两者都须对方同意。关闭协商弹窗不代表回复，可从“查看协商请求”继续处理。刷新和短暂断线后自动重放房间日志。主动返回本地后不会自动重入，可从联网菜单恢复。房主可重置访客席位让新访客接续当前局，或关闭房间。

联网使用 `quarto-net-v1` 消息协议（`init`、`action`、`propose`、`respond`）。每局有独立 `roundId`，操作绑定局面 `base`，接收方校验席位、回合、参数和规则；非法日志暂停对局并保留最后可信局面。Portal 只负责身份、房间和有序传输，不判定游戏规则。服务端不需要登记 Quarto 或重新部署，仅需发布静态文件。

联网不写入本地棋局存档，退出后恢复进入联网前的本地状态。房间与邀请状态使用 `quarto.*` 的 sessionStorage 命名空间；身份凭证由 Portal SDK 管理。遵循 Portal 的双席位、有限日志和邀请／会话有效期，不支持观战或多人。
