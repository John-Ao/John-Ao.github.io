# Quixo

静态页面，无运行时外部资源。同屏双人及基础人机，遵循 [Gigamic 官方双人规则](https://export.gigamic.com/wp-content/uploads/2021/01/INS-RULES_QUIXO_03-2017.pdf)：5×5 棋盘只能取外围空块或己方块，翻成己方符号，从所缺行/列另一端推入，不能塞回原口。所有中间方块滑动，横竖或两条大对角线五连获胜。行动导致对手五连时对手获胜，即使自己同时连线。

选择外围块后点绿框端点，界面预览滑动后的完整棋盘，再确认。未确认预览不写存档，取消或刷新还原。支持方向键、Enter / 空格、重绘焦点恢复、撤销、新局确认及自动保存。

AI 检查对手一步回应，评估未受阻连线，并对最近重复棋盘施加选择惩罚；同分采用随回合变化的确定性扰动，降低机械往返。不会因为重复局面而凭空结束对局；双方可重开。基础 AI 不保证最优。

```sh
node --test game/quixo/model.test.mjs
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs GAMES_URL=http://127.0.0.1:18769 node game/quixo/browser.test.mjs
```

浏览器测试覆盖 1280×800、390×844、320×844、844×390，含键盘选择/推入/确认、预览与存档隔离、撤销、AI、规则、同时连线的对手获胜及恢复。模型覆盖端口约束、行列滑动、双方同时五连优先级和完整 AI 对局。
