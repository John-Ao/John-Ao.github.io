Schotten Totten — 本地双人触屏游戏

运行
直接打开 index.html，无构建、无依赖、无后端。
或在本目录运行 python3 -m http.server 8000，再访问 http://localhost:8000。
手机和平板可通过同一局域网访问电脑的 HTTP 服务。

玩法覆盖
- 官方基础玩法：54 张氏族牌、9 块界石、三连或五块获胜。
- 战术变体：独立牌堆，7 张起手，全部 10 张战术牌（9 类，百变者两张）。
- 百变者、间谍、盾卫、迷雾、泥战、招募者、调度者、女妖、叛徒。
- 战术使用数量限制、每人整局一张百变者、公开弃牌与不同牌堆补牌。
- 专家变体：回合开始占领，出牌后不得占领；可与战术变体组合。
- 多局积分：赛前指定局数，胜者加 5，败者按已占领界石计分。
- 先手由双方手动指定，便于遵循官方“最近去过苏格兰者先手”。

触屏操作
本地模式双人共用一台设备，轮流查看手牌；跨设备使用下文的联网或面对面扫码配对。
点手牌，再点界石。调度者/女妖/叛徒需要先点击棋盘上的目标牌。
调度者随后点击目的界石或“弃置目标牌”；叛徒点击己方目的界石。
招募者点击“发动招募者”，选择牌堆抽牌，再点击两张手牌退回。
占领阶段点击高亮界石，之后选择牌堆补牌并交接。
对坐模式旋转玩家 2 操作区及上方阵型；窄屏横向滑动棋盘。
精锐牌属性在占领时自动取最强组合，放置时不会锁定。

实现约定与边界
提前占领仅使用已公开普通牌及弃牌，考虑场上精锐的最优属性，
不读取任何手牌，也不假设未来会使用战术牌。
规则书未细述的招募者牌堆不足情况：抽完剩余牌，再退两张；
手牌未达上限时按常规补牌。两堆均空时不能发动招募者。
无合法普通氏族牌时可以跳过出牌；跳过不补牌。
多局最终同分记为平局，下一局先手由双方选择。
连续跳过且双方无任何合法出牌/占领时，可双方同意和局，本局不计分。
此僵局处理为可选补充约定，并非官方规则书规定的胜负条件。
没有引入 Schotten Totten 2 的城堡/攻守规则；那是另一款游戏。

存档
v2 对局保存在当前浏览器 localStorage，刷新后重新遮住手牌。
旧基础版 v1 存档保留原键，不删除、不迁移，v2 从新对局开始。

## 联网与面对面扫码对战

通过 HTTPS 或 localhost 打开页面，点击「联网」：
- 「创建房间」经 Portal 登录后生成邀请链接，对方打开并加入。支持刷新恢复、自动重连、手动同步、重置访客席位及关闭房间。
- 「面对面扫码配对」无需 Portal 登录。两台设备连接同一 Wi-Fi／热点，房主展示二维码，对方扫描后展示应答码，再由房主扫描。也可导入二维码图片。通过 WebRTC 直连，无 STUN/TURN 或服务器中转。

房主为玩家 1，访客为玩家 2；开局使用房主当前玩法配置重新发牌。只有当前行动席位可以操作，秘密手牌／选项不会展示给另一席位。操作须经传输确认后才改变局面。断线、等待确认或协商期间不能行动。

联网菜单支持双方协商悔棋、重开及认输；多局游戏的下一局也需双方同意。悔棋撤回最近一个已确认操作（可能是出牌、抽牌或效果选择中的一步）。返回本地对局会恢复连接前的本地状态，联网状态不会写入本地游戏存档。

面对面连接刷新或关闭页面后不能恢复，需要重新配对开新局；网络隔离、浏览器本地网络权限及锁屏可能阻断直连。尚需实体 Android / iPhone 及手机热点验证。

与 Tacta 一样，共享操作日志可重建完整牌局，按席位隐藏只提供正常界面下的保密，不防开发者工具窥牌，适用于诚信对战。当前原版规则与组件覆盖限制仍见上文。

共用协议与房间界面：`../board_shared/online-protocol.mjs`、`../board_shared/network.mjs`；玩法适配器在 `../board_shared/adapters.mjs`（失落的城市为本目录 `online-adapter.mjs`）。

仓库根目录验证：

node portal/tests/boards-nearby-browser.mjs
node portal/tests/boards-portal-browser.mjs
