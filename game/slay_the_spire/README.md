# Slay the Spire · 桌游规则版

无依赖的静态 HTML/CSS/JavaScript 游戏，同一台触屏设备上的双人合作。推荐平板横屏；窄屏会改为上下两个玩家区。直接打开 `index.html` 即可，也可由任意静态 HTTP 服务运行。无联网游戏、账号、安装或构建步骤。

## 操作

1. 两位玩家分别选择涅奥祝福。每人初始 5 金币，无初始药水。
2. 在各自操作区选择下一房间；双方同意同一节点后前进。
3. 战斗中先在自己的目标栏选择敌人，再点手牌。群攻另外选择一行，首领始终包含在群攻范围内。
4. 两人可交错出牌。需要弃牌时，点击手牌选择弃牌；升级铁斩波需选择其效果。双方结束行动后才结算敌人阶段。
5. 小刀是可跨回合保存的标记。使用药水不消耗能量。战斗外可赠送药水和交换站位。
6. 点击“查看升级”对照原牌与升级牌，点击牌组查看永久牌组。规则面板包含核心规则及当前实现范围。

## 本次还原

- 按官方规则书修正：中毒不衰减、回合末扣生命；虚弱与易伤相互抵消；多段攻击只消耗一枚状态；群攻作用于一行及首领；能量、力量、格挡、状态和小刀上限。
- 逐牌定义数值和升级，不再统一加一；补上生存者和匕首投掷的弃牌、铁斩波的模式选择、保留、虚无、晕眩、黏液、灼伤和小刀。
- 第一幕两套 13 层分支地图与深浅色随机房间标记。恢复首次遭遇与普通遭遇分堆、敌人固定/骰子/循环行动、每行召唤物、三精英、三首领及模式切换。
- 有限奖励牌堆：普通牌两张，罕见和稀有牌各一张，金券揭示稀有牌，未选牌回牌堆底。可在选择卡牌前查看本场其他奖励。
- 具体遗物、药水、涅奥祝福、事件；商店共享库存、稀有度定价、第一件遗物折扣、每人一次移除和队友金币资助。
- 双人独立触点、手牌横向滚动、自动存档。新存档使用 `sts-tabletop-v2`，保留旧版 `sts-touch-v1`，不自动迁移不兼容的旧版规则状态。

## 还原边界

这是**遵循桌游核心规则的第一幕有限内容实现**，不是官方产品或完整实体桌游移植。

已实现：铁甲战士与静默猎手、30 种玩家牌、4 种首次遭遇、9 种普通遭遇、3 种精英、3 种首领、6 种遗物、7 种药水、7 种涅奥祝福组合、4 种事件。

尚未实现完整牌库、全部普通遭遇/事件/遗物/药水、故障机器人和观者、第二至第四幕、升阶、解锁与首领遗物选择。内容子集改变了抽取概率与整体平衡。地图和具体数值参考公开社区桌游改编项目，并非全部逐张核对实体牌；未核实的多人生命值与其他差异见 `SOURCES.md`。界面中文为本实现译名，未使用官方中文牌面或原画。

## 验证

运行：

```sh
node tests/engine.test.cjs
node tests/touch.test.cjs
```

引擎回归测试涵盖状态结算、目标行、多段伤害、弃牌锁定、升级、抽弃牌、保留/虚无、能力触发、商店、药水、召唤和胜负。24 个种子的全路线状态流转测试使用强制击败敌人来检查流程，不代表平衡性或正常出牌通关测试。

浏览器检查包括涅奥选择、路线共识、双方结束回合、自动存档、390 像素窄屏与 1024 像素平板布局。真实双人触屏设备尚未实测，多点触控通过事件模拟回归测试。

## 文件

- `data.js`：卡牌、升级、敌人、物品、遭遇和祝福定义。
- `maps.js`：两套第一幕节点及连线。
- `engine.js`：随机状态、战斗、奖励、商店和存档。
- `game.js` / `style.css`：中文界面、触控、布局。
- `SOURCES.md`：来源、确认程度与已知限制。
- `tests/`：可直接用 Node 运行的回归测试。
