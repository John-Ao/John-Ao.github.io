玩法与还原范围

九名船员，双方各控制四名；Sofi Odessa 由当前船长控制。两人在同一块触屏上选择自己的船员，每回合结束交接船长。

  1. 船舶行动：选择不同于上一回合且未损坏的房间。领取指令、抽牌和船舱效果可以自行安排顺序。超出三张手牌时先弃牌。
  2. 事件：抽取并完成事件，再执行两次行动。可重复选择航行、探索、市场、港口；跳过一次行动获得一指令。
  3. 挑战：允许零人参与。每人增加一疲劳，另一玩家参与需付一指令（不按人数重复收费）。抽命运后，双方可弃掉匹配技能的手牌加值，再确认结算。
  4. 航行：最多选择当前玩家控制的一名有工艺的船员。总值 0–3 / 4–6 / 7–8 / 9+ 对应 1 / 2 / 3 / 4 格；每步走相邻海域，遭遇危险先完成检定。
  5. 战斗：双方各两枚行动标记，每人每轮至多攻击两次。选择船员和目标，抽命运，使用协同，再安排伤害。格子可构成分支，但必须正交相连，不能经过旧伤害；至少一半伤害落在主目标。双重心消耗两伤害。覆盖全部心才击败敌人。
  6. 命中后存活敌人反击；未命中先承受反击，再造成一点伤害。两疲劳使伤害减一。反击可用武器格挡，轮末攻击不能用武器格挡。溢出伤害由玩家分配。
  7. 港口一次行动内可住宿、修船、治疗；住宿四金币，全员恢复二生命并去一疲劳；每金币或材料修一点船损；每金币完全治疗一人。
  8. 普通模式全员倒下或船损达十一时，返回最近港口并恢复对应损伤，丢弃六事件后继续。残酷模式直接失败。

已按规则实现

有限的十四枚指令、九名船员与船长归属、能力牌抽取/弃牌/装备上限、命运牌堆与洗牌、五种状态、六个受损区域、甲板逐次搜索、三层事件牌堆、挑战抽牌后修正、移动距离、格网战斗、溅射与九种协同、普通/残酷模式。

仍需实体内容

地图、探索段落、事件效果、市场装备、能力牌特效及战役结局使用示例或人工结算，不是完整官方战役。六十张能力牌的名称、命运、技能与费用根据官方组件清单录入；自动处理抽牌、装备与技能加成，专属特效需按实体牌结算。船员基础值据公开规则书图示录入，专属技能与升级牌由“实体卡结算”处理。未自动实现全部敌人特性、持续事件、全部食谱和冒险卡。伤害放置界面允许舍弃余量；Rafael协同目前仅支持攻击修正阶段使用，其他格挡时机需手动结算。示例事件的低落默认给当前选中船员；示例毒性敌人的状态与轮末伤害落在同一目标，实体玩法可手动重新分配。

实体组件辅助模式可以录入检定、敌人格网、段落、关键词、奖励和卡牌效果；需配合自己的游戏地图、剧情书和实体牌。第一/二/三次事件牌堆耗尽时分别提示剧情书 1、1.2、F1，不再用“三图腾返港”冒充官方胜利条件。

手牌默认隐藏，点击各自区域的“查看手牌”；同屏隐私依赖双方回避。进度保存于浏览器；旧版简化存档保留但不混入新版。
