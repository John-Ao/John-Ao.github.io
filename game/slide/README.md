# 滑动拼图

直接打开 `index.html`，或通过静态 HTTP 服务访问本目录。无需依赖和构建。

- 默认使用滑动模式；已有存档保留所选模式。左上角菜单中通过分段滑动开关：选择 2×2、2×3（两行三列）、3×3、4×4，以及点击或滑动模式。
- 顶部居中显示毫秒计时器，默认开启，首次有效移动开始计时，完成后停止，之后手动移动不会重新计时；仅点击骰子打乱会清零计时，重置棋盘保留用时；菜单可暂停、继续或关闭计时，菜单内可分享局面；顶部太阳/月亮、骰子、环形箭头按钮分别切换日夜模式、打乱和重置。
- 初始及重置局面按行排列数字，右下角为空白。打乱使用合法移动，保证可解。
- 点击模式：点击空白相邻格子自动移动；按住拖动经过格子连续触发，快速拖动不会跳过中间格子。
- 滑动模式：拖动与空白同一行或列的格子，夹在两者之间的数字一起移动。滑块以手指移动速度的 1.6 倍跟随，沿正确方向拖过约 22% 格距后松开即完成，否则回弹。取消手势不改变局面。
- 一次单块或多块移动计为一步。支持键盘方向键、Enter / 空格操作。
- 保留主题、低亮度、全屏、计时、暂停、分享和本地状态保存；更改尺寸重新打乱，更改操作模式保留局面。

规则检查：`node slide/test.cjs`（从工作区根目录运行）。
