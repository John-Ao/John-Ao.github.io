# 推箱子

静态 HTTP 服务打开 `index.html` 即可游玩。共 **60 个原创固定关卡**，覆盖 6×6、7×7、8×8，每组 20 题；按棋盘尺寸选关，不把搜索统计伪装成人工难度评级。

方向键或 W/A/S/D 移动，也可点击人物相邻格或屏幕方向按钮。每次只能推一个箱子；绿色带勾箱子表示已经归位。撤销按实际移动步恢复。 支持重开确认、逐关自动保存、撤销、规则弹窗及小屏放大。放大后可左右滑动棋盘。

## 离线关卡生成

```sh
node game/sokoban/generate.mjs
node game/sokoban/generate.mjs --check
```

固定 LCG 种子 `0x534f4b4f`。生成文件 `levels.mjs` 已入库；浏览器直接读取题库，不运行生成器。`--check` 重新执行完整搜索，逐字比较结果且不写文件。请勿单独格式化生成数据；改动生成算法时须重新生成并验证。

先生成相互不同的墙壁布局，把双箱或三箱放到目标上，再让人物移动并逆向拉箱构造起点，保存完整逆拉轨迹。随后用独立正向 BFS 验证可解性和最少推数：每条边恰为一次推动，人物在同一可达区域的状态合并；保存各次推动之间的合法行走路径。每题最多扩展 60,000 个状态，耗尽返回 `complete: false` 并拒收。6/7/8 格关卡分别要求至少 4/6/8 次推动。60 题的墙壁布局也彼此非旋转镜像重复，避免仅变换目标或起点凑题。

对四种旋转及其镜像取规范编码去重。题库数据保存答案及可复查的搜索指标，前端判胜依据规则而非对比预设答案。 `proof.minimumPushes` 是正向 BFS 证明的最少推动次数，不声称最少总步数。

## 验证

```sh
node --test game/sokoban/model.test.mjs
GAMES_URL=http://127.0.0.1:18769 node game/sokoban/browser.test.mjs
```

模型测试覆盖全部 60 题、规则边界、旋转镜像去重、预算耗尽处理及固定种子复现。逐题验证逆拉轨迹重放和正向解答，独立重算最少推数；包含双箱、三箱与禁止同时推动两箱。

浏览器测试默认使用已安装的 `playwright` 包和 `/usr/bin/google-chrome`，可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 覆盖。实际检查 1280×900、390×844、320×844：鼠标/触屏、键盘、撤销、刷新恢复、重开取消与确认、规则弹窗、尺寸选关、放大后触摸横移、最大尺寸最后一题完整通关和页面横向溢出。截图输出 `/tmp/sokoban-<宽度>.png` 及相应 `-won.png`。

存档键为 `sokoban-v1`，按题目索引保存；撤销记录不跨刷新。后续扩充应追加题目，避免改变已有题目索引含义。没有运行时随机出题或自动提示功能。
