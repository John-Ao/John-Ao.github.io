# Spirit Island · 双人同屏合作

纯 HTML/CSS/JavaScript 静态游戏，无安装依赖、账号或远程服务。打开 `index.html` 即可玩；两位玩家各操作自己的精灵，共同抵御入侵者。建议使用横屏平板或桌面触屏。

也可在此目录运行：

```sh
python3 -m http.server 8080
```

随后访问 `http://localhost:8080`。手机和平板可访问电脑的局域网地址；这是同屏游戏，不支持不同设备之间的状态同步。

## 已实现

- 四位低复杂度基础精灵：雷霆迅击、阳光下奔涌的河流、大地之力、如焰闪烁的暗影。各自的成长、能量／出牌轨道、特殊规则、元素、先天能力和 16 张专属牌。
- 基础牌库的 36 张次要能力、22 张主要能力，包括抽四选一、主要能力遗忘、牌堆重洗、重复能力、借用灵迹、赠牌、恢复灵迹和触发伤害。
- 15 张恐惧牌，按三个恐惧等级结算；恐惧提升与胜利条件。
- 两张基础枯萎卡、可选无枯萎卡入门规则；初始枯萎使用 +1 勘误。
- 普鲁士 0–6 级：初始额外城镇、阶段 II 扩张、牌堆缩短／调整、恐惧牌数量调整。
- A–D 岛板中任选两块，使用参考数据的地形、初始单位、板内相邻关系。
- 成长 → 选牌 → 快速 → 入侵者 → 慢速 → 时光流逝；自动建造、探索、蹂躏和达汉反击。
- 自选成长项目顺序、放置灵迹的轨道及土地、逐点伤害分配、逐个聚集／推移、枯萎连锁及蹂躏顺序。
- 双人独立选牌，结算时使用带步骤编号的队列防止重复提交。玩家二面板可翻转。
- 自动保存、JSON 导入／导出、最多 100 步撤销。旧版 v1 存档保留但不兼容新版。

## 尚未覆盖与差异

本项目是基于官方规则的非官方实现，**尚不是完整官方数字版**。

- 其余四位基础精灵（蔓延繁茂绿意、雷语者、海洋饥饿之握、梦魇与恐惧使者）尚未实现。
- 英格兰、瑞典、基础场景、主题岛板及扩展尚未实现。
- 岛板采用抽象视图；板内连接使用参考数据，板间固定连接为 7↔7 和 8↔8，是明确标注的自定义拓扑，尚未复刻官方拼接图，会影响距离与难度。
- 达汉承受蹂躏伤害时自动集中伤害，不能手动选择具体受伤达汉。
- 自由选择先天能力最高层级，但不是逐条开关元素门槛。复杂重复效果目前限制同一张牌每轮接受一次授予的重复；多个不同授予来源对同一牌的重复组合尚未完整覆盖。
- 中文名称与机械效果为本项目整理的摘要，未复制原版美术或完整规则书。个别极端组合仍可能需要修正；可通过撤销恢复。

## 操作

1. 选择不同精灵、不同岛板、对手等级、枯萎规则后开始。
2. 每位玩家选择成长组合，在中央依次选择成长项目；放置灵迹先选轨道，再选合法土地。
3. 成长完成自动领取能量。点击能力牌选入本轮，再次点击可撤回并退还费用。双方确认后进入快速阶段。
4. 点击已出的可用能力或先天能力，选择目标，按中央提示完成伤害、移动等操作。元素自动计算且不消耗。
5. 双方点击结束阶段后，系统推进。需要共同决策时会暂停，直到完成中央步骤。
6. “规则”内可随时查看流程、胜负、范围、恐惧与枯萎说明。

## 验证与文件

```sh
node --test engine.test.js
```

测试覆盖规则基础、不合法操作、抽牌／遗忘、复杂主要能力、100 局不同精灵和对手的终局推进、74 张能力的高低门槛结算、15 张恐惧牌的三个等级。测试证明这些路径可执行，不代表穷尽了所有官方互动。

- `engine.js`：规则状态与逐步结算引擎，可由 Node 独立测试。
- `cards.js`、`spirits.js`、`boards.js`：能力元数据、精灵与岛板资料。
- `powers.js`：中文机械摘要和能力效果。
- `app.js`、`style.css`、`index.html`：界面、触屏、保存与规则说明。
- `SOURCES.md`：网上规则与参考数据来源。
- `tools/import-reference.py`：从指定本地参考资料提取牌面元数据的开发工具，运行游戏不需要它。
