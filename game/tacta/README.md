# Tacta · 点到为止

双人同设备、同页面轮流游玩的静态卡牌游戏，支持鼠标、触摸和键盘落点选择，无依赖、无构建步骤。

当前依据官方基本轮流规则实现。已移除原先的2×2网格改编。**18张牌中8张完整布局尚待核实，几何比例和起始牌也存在近似，不能宣称原版完整复刻。** 资料、逐张核对状态及已知差异见 [RESEARCH.md](RESEARCH.md)，右上角菜单中也提供牌面目录。

## 打开

直接在浏览器打开 `index.html`，或在此目录运行：

```sh
python -m http.server 8080
```

电脑访问 `http://localhost:8080`；同一局域网的平板访问 `http://电脑的局域网IP:8080`。双方在同一台设备操作，没有跨设备同步。

## 界面

主界面按浏览器可见高度自适应，无需横向或纵向滚动。顶栏显示比分，候选牌始终竖排在右侧，牌桌占据其余空间；没有底部出牌栏。规则、牌面资料、交接设置和重新开局统一收进右上角菜单。长篇说明弹窗只在内部滚动，不影响游戏页面。

## 操作

1. 从右侧两张候选牌中选择一张。选中牌的左上悬浮按钮逆时针旋转45°，右上按钮顺时针旋转45°，下方中央按钮镜像翻面。
2. 点击桌面上的「＋」预览合法落点，也可用左右箭头逐个浏览。点击「确认落牌」才会实际放置。
3. 默认出牌后遮屏交接，可关闭「自动交接遮屏」，或随时手动遮屏。
4. 单指拖动桌面平移，双指捏合围绕双指中心缩放并可同时平移；电脑支持鼠标拖动及围绕指针的滚轮缩放，也可用＋/−按钮缩放。「全览」显示牌局，「桌界」显示开局固定的完整桌面。视角不会改变边界。
5. 只有两端牌全部方向无合法连接时，才可点击桌内空白位置独立放置；不得接触其他牌。
6. 所有牌打完自动结算；也可通过菜单中的「查看结算」重新查看已结束的对局。

会自动保存已确认的对局；刷新后继续，未确认的预览不保存。使用新的 `tacta-standard-v2` 存档键，旧网格存档保留但不加载，避免误用完全不同的牌面和坐标。隐私模式或存储被禁用时可能无法保存。

## 文件

- `cards.js`：18张明确的几何牌面定义、起始牌，以及各牌资料核实状态。
- `engine.js`：多边形裁剪、遮挡、匹配、桌界、回合、计分和存档校验。
- `app.js`：SVG牌桌、候选位置预览、鼠标/触摸交互与同屏交接。
- `style.css`：响应式布局。
- `gestures.js`：独立的桌面手势控制与视角变换；拖动、捏合和中断手势不会触发落点选择。
- `gestures.test.js`：缩放锚点、双指转单指、误触拦截、手势中断和滚轮测试。
- `engine.test.js`：几何、规则及完整对局测试。

## 验证

```sh
node --test engine.test.js gestures.test.js
node --check cards.js
node --check engine.js
node --check app.js
```

测试覆盖错位、大小不同、跨牌覆盖、桌界、空心覆盖实心、独立放置条件、遮挡计分、先手排序、存档，以及20局完整对局。它们验证实现与上述几何规则一致，不代表待核实牌面已经得到原版认证。

菜单中的「双列布局」固定左侧为玩家 2（橙方）、右侧为玩家 1（紫方），双方都显示牌堆两端，只有当前回合玩家可以操作。「玩家 2 对面视角」将其整组手牌与操作区旋转 180°，并显示同向的双方比分、回合提示；交接遮屏及结算也随玩家 2 的当前视角旋转。两个选项独立生效并保存在本机，不修改牌面或落牌规则。

页面与牌桌使用中性灰底色。菜单勾选「夜间模式」切换为深灰主题，取消勾选回到日间主题；首次打开参考系统深浅色偏好，手动选择后记住设置。主题切换不影响对局、缩放或双列布局。
