# Targi

支持双人共用触屏、轮流操作的静态网页游戏。直接用浏览器打开 `index.html`；也可在此目录运行 `python3 -m http.server 8080`，访问 http://localhost:8080 。无需安装依赖或联网。

## 当前实现

- 基础版 45 张部落牌、19 张货物牌，逐张费用、分值与特殊能力。
- 族人放置与交点、六种特殊边界行动、手牌、可选支付、重排部落、生产、袭击、资源上限、完整终局与平分判定。
- 手机和平板触屏操作，对坐旋转、撤销、自动保存、牌表、规则和分数明细。

范围为基础版，不含大型扩展、行动代币等小扩展或单人变体。两处资料歧义及采用的处理方式见 RULES.md；并非出版社认证实现。

浏览器按访问地址保存进度。旧改编版存档保留，但不与新版牌组混用；新版另存。清除浏览器数据会清除进度。

## 文件

`cards.js` 卡牌资料；`engine.js` 规则引擎；`game.js` 交互；`style.css` 布局；`RULES.md` 规则依据和校核说明。

## 验证

运行 `node test.cjs`：27 组检查，包含 200 局自动完整对局，检查牌张守恒、资源非负、流程结束，以及全部能力与关键边界规则。浏览器已检查手机和平板布局、落子、建造、牌表、撤销和刷新续局。
