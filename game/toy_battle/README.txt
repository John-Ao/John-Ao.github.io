Toy Battle — 双人同屏静态网页游戏

打开 index.html 即可游戏，不需要安装依赖或服务器。
手机和平板可以通过任意静态网站托管访问；同一设备两人轮流触屏操作。
点击“选择地图 / 新局”选择地形。点击手牌，再点击金色框基地。
换手时手牌自动隐藏，可开启红方操作区旋转 180°，供对坐使用。
对局自动保存在当前浏览器。新版存档与旧城堡版独立，不读取旧版棋局。

已实现
- 八种官方兵种及全部效果，包括 Cap’n 连锁、随机弃牌、可选效果。
- 全部八张基础地图，按原版道路、区域和勋章目标重新绘制：
  城堡 7、泳池 6、云中城 8、火山 7、墓地 7、海域 5、空间站 7、战场 8。
- 官方 La Croisette 扩展地图，目标 6。
- 撤回、补兵、移兵、复活、封锁手牌、战力限制、效果屏蔽。
- 多总部连线与攻占任一敌方总部、永久区域勋章、无行动终局。
- 可选入门模式：忽略特殊基地的效果和限制。
- 公开叠层、弃牌查看、回合记录、浏览器本地存档、中文规则查询。

这是采用简化图形和符号的非官方实现，地图保持道路关系和区域规则，
不使用商业棋盘插画。无电脑对手或跨设备联机。

验证
node engine.test.js
定向规则检查及九张地图各 100 局固定种子随机对战，共 900 局；
每一步验证全部 40 枚在用棋子的数量与唯一性、手牌上限，并检查正常终局。
浏览器实测地图切换、手机尺寸布局、部署与自动换手。

文件
maps.js：九张地图的基地、道路、区域、目标及特殊规则。
engine.js：独立规则引擎。
app.js / index.html / style.css：静态页面和触屏操作。
rules-zh.pdf / player-aid-zh.pdf / croisette-zh.pdf：官方中文资料。
sources.txt：规则与地图核对来源。
